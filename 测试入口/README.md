# 测试入口

双击任意一个 `.url`，直接用默认浏览器打开那一关的关头（`?level=数字`）。
不用改地址栏，也不用从第一关点进去。

- `00-全部关卡（分段目录）` 走游戏自带的 `?test` 页，一屏列完 16 关和每个分段，点哪个进哪个。
- `90-空白分页` / `91-校园网登入页` 是两个调试入口，调浏览器版面时用。

这堆文件是生成的，别手改：关卡名或关卡数变了，重跑一次

```
node tools/做入口.mjs
```
