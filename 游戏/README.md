# 游戏 · undo

可玩工程。租客章慧琪视角。一进就是租盘网站「廿八屋」。

## 怎么开

双击 [打开游戏.bat](打开游戏.bat)，或打开 [index.html](index.html)。

第一章十六关，四段：住进来（1–3）、夜里（4–7）、星期六（8–12）、上门（13–16）。第二章未做。关卡表见 [第一章关卡](../策划/剧本/01-第一章-关卡.md)。

每关开头不弹框：整屏换成这一关的场景图，中间淡出一句要做什么，点下面的「嗯……」进去；不显示第几关和关卡标题，日期只看右上角的钟。日记簿分三个签（要做的／收集的／我写的），页码在签里各自从 1 数起，一页放不下续到下一页，用「‹ 1／3 ›」翻，翻过头尾就到隔壁的签，不滚动。「要做的」是这一关的清单、作业卡（每条要求对一张纸，有了打勾）和这一关收到的东西；「收集的」把证物和笔记按日子排，可切「按东西」（车、水喉、储物室门……，表在 `diary.js` 的 `ITEM_ABOUT`），和证物重复的笔记不另列；「我写的」是四条、屋里的样子、带给他的纸、在诊所交了什么和分两堆；「收集的」里这一关以前的日子收成一行「以前的日子」，点开才列；「按东西」连纸也列进来。从目录点开的证物，底下列出同一样东西里最相关的三样。日记簿里每一层都能逐级返回：目录 → 证物或操作页 → 同一样东西的下一张，「‹ 返回」一层层退，退到底是「‹ 回到目录」，回到原来那个签那一页；Esc 和点弹窗外面也是退一层（`ui.js` 的 `diaryOpen`／`diaryPush`／`diaryBack`）。剧情里直接弹出的操作页（交给罗启明、分两堆等）没有上一层，仍只有原来的按钮。第一页是这一关的清单，可做的项用虚线圈，不另写字。打了勾的「要做」都做完，右下「往下」才亮。过关不另开结束画面：上一关放进日记簿的东西、下一关的日期地点和要做的事在同一个画面依次浮出，只点一次。第 1 关发完留言后的「他夜间不在线」、第一章结尾也是同一套字幕样式。看过的线索卡变灰，东西变了会亮回来；地图上看完的地点变灰；日记簿里没打开过的证物前有红点（`story-*.js` 的 `hot`／`hotSeen`，`hub.js` 的 `hubPlaceDone`）。能记的字只在正文画铅笔线（不画标题）；第 3 关叫「屋里的样子」，夜里才说「搬进来那晚／今晚」，不写「本来」。热点线索一律先开奶油 scene 弹窗，不按「能不能记」换壳；可记只是正文多铅笔线。日记本样式只留给目录和操作页（摆在一起、对照纸等）。

当面是现场对白；电话是听筒，陈的诊所地址也在这部手机里；站内留言走廿八屋；倾偈只和表姐，聊完仍在这扇窗；丽芬那句是语音留言。墙簿是熟人页。日记簿不在墙上。不要混成同一块论坛壳。

底栏左边的按钮叫「浏览器」，打开桌面上的 IE（廿八屋、墙簿两个分页）。墙簿的熟人动态、收件箱、藤先生广告跟着游戏钟和剧情变（数据在 `web-data.js` 的 `WALL_FEED`／`WALL_MAIL`，对照表见第一章「墙簿跟着剧情走」）。有没看过的，「浏览器」三个字慢慢明暗、亮红点、叮一声，点进去直接到墙簿；新动态浅黄底带「新」字。能记的那几个字画在正文里（绿铅笔下划线，点了变淡，网页上不写「已记下」），写进日记簿笔记，不挡过关。熟人的帖可以「回应」（点开后在帖下展开预制草稿，发送或删掉；多句可选时先点切换再发送。对方有回的等离开这页再回来才出现，`answer`／`mute` 字段；打不出字的用 `mute` 飘一句提示，不弹网页框）；侧栏有好友在线（跟着钟，`wallStatus`）、中秋倒数、你可能认识；个人页列这个人的动态（`wallTimeline`）。

**改对话**：[改对话工作流](../策划/剧本/改对话/改对话.md)（先剧本或导出表，再 `story-*.js`）。对稿：[第一章](../策划/剧本/01-第一章-章慧琪.md)。分支总表：[对话分支](../策划/剧本/08-对话分支.md)。关系：[人物关系图](../策划/人物/人物关系图.md)。人设参考：[图/人物](../图/人物/)。

本目录是唯一可玩入口；剧情在 `assets/story-early.js` · `story-clinic.js` · `story-late.js` 等分模块脚本。

## 存档、跳关

- 每进一关在关头自动存一档（浏览器 localStorage，键 `undo-ch1-save`）；关内进度离开页面时也会记下。再打开是开局存档卡（`levels.js` 的 `resumeCaption()`）：标题、一条垂下来的书签带标出存档那一页（日子、地方、要做的事，顶栏时钟同步成存档时间），下面「继续」「选关」「重来」。选关在卡里换页，按四部分分组，只列玩到的关，没玩到的不列；上次那一关和首页一样用细线框住、挂书签带；选较早的关重开或点「重来」都先在卡里确认一次，后面的进度会清掉。打完结局清掉存档。
- 通关另记一个键 `undo-ch1-cleared`（`{ first, last, times }`，`levels.js` 的 `markCleared()`），不跟存档放一起，清档、重来都不碰它。
- 结局画面有「第二章　预告」：`story-late.js` 的 `CH2_TEASER`，取自 [第二章](../策划/剧本/02-第二章-陈家豪.md) 2-1 楼梯，停在他撞门。
- 调试跳关：`index.html?level=N`（N = 1–16）。前面各关的必拿物和笔记会自动补上，不读存档。
- 分段测试：`index.html?test` 出一张目录，每关「从关头」和关中间的几段都能点。也可以直接写 `?level=N&seg=b`（段号见目录，段表在 `levels.js` 的 `SEGS`）。第 10 关只有关头。
- 旧链接 `?preview=1..26` 仍然能开，按 `PREVIEW_TO` 对到现在的关和段。

关于章自己的事（电表、没回的短讯、她想再来）只弹一句提示（`ui.js` 的 `tip()`），不进日记簿。日记簿只收屋里和别人身上的事。

清单任务可以写 `after`（做完才显示的具体说法）和 `show`（到时候才出现），`hint` 可以是函数。事情发生前，清单只写中性的说法，免得先剧透。规则见 [第一章关卡](../策划/剧本/01-第一章-关卡.md)「不准先知」。

脚本是普通 `<script>`，按 index.html 里的顺序载入，共用一个全局。已拆分的 stub（`story.js`／`web.js`／`style.css`）不要再挂进页面。改了 JS／CSS 记得把 index.html 里的 `?v=` 一起改。

改完任何东西，在仓库根跑一次全量检验（不抽查）：`node tools/全检.mjs`。它检查 JS 语法、index.html 是否纯 ASCII 及引用、函数重名、缺图、缺音效、每句角色台词有没有普通话（含不走 `line()` 的裸对象）、粤普互串、选择有没有后果、禁止的旧写法（地名、人名错字，规则见 `.cursor/rules/`）、控制字符和乱码。有 ERROR 退出码为 1；WARN 要人工逐条看完。

## 声音

右上角「环境音」按钮切大／小／关，只关地点里循环的环境声。对话翻页、按钮、纸、电话、字幕底乐、录音底噪都不走这个开关。记在 localStorage（键 `undo-sfx`）。浏览器要玩家先点一下才出声。

顶栏另有两个开关，同样只存在本地、不进存档（`core.js` 的 `optButtons()`）：

- 「粤＋普／粤语／普通话」：三档切换（键 `undo-lang`）。`粤语` 与 `普通话` 各取一侧；`粤＋普` 是粤语为主、在角色台词下面加一行小字普通话对照（旁白没有普通话侧，仍只显示粤语）。有双语来源的文本走 `core.js` 的 `T()`；只有一种写法的界面文字、关卡清单、网页内容走 `H()`，粤语／粤＋普时转香港繁体，普通话时保持简体。
- 「字　中／大／特大」：对白字号 ×1／×1.15／×1.3（键 `undo-size`），改的是 `--say-*` 这几个 CSS 变量。

只用屋里本来会有的声音，不配恐怖音乐、不做突然吓人的响声；诊室刻意几乎无声。

- 界面音、来电铃、拨号、短讯、倾偈、打字、录音键、字幕底乐、录音开着时的磁带底噪：`sfx.js` 里用 Web Audio 合成，不用文件。代码里写 `sfx("名字")`，名字见 `SFX`。
- 翻开日记簿、合上日记簿、点开大图、摊开地图、纸放回去用录音（Pixabay：Page Turn、Book closing、Paper Page Flip and Document Rustle、Letter Opening、Closing a Book），见 `SFX_FILES`，文件 `assets/sfx/操作-*.mp3`，音量已调进文件里，跟合成音差不多响。换了同名文件就改 `SFX_REV`。
- 环境声：按地点自动换，循环播放。音量和淡入淡出走 AudioContext 的增益节点（`ambWire()`），不改 `audio.volume`——iOS 不许网页改它，改了也没用。把 mp3 放进 `assets/sfx/`，文件名照 `AMB_FILES`（如 `环境-后座夜里.mp3`、`环境-澄心诊室.mp3`）；只用真实录音或现成音乐，不用代码合成环境声，缺文件的地点就静着。用同名文件替换后，把 `sfx.js` 里的 `AMB_REV` 改一下，不然浏览器会放旧的。现有文件取自 Pixabay（Pixabay Content License，不用署名），已剪成首尾无缝循环、调过响度：街道 -28、天台和表姐家 -30、后座入住、后座白天和候诊 -32、后座夜里 -35、楼梯走廊 -36、诊室 -38 LUFS；来源链接在试听页。后座入住、后座白天、后座夜里都是音乐，不是环境实录：入住是 Clavier-Music 的 Lonely – Beautiful Piano Music（`环境-后座入住`），白天是 Documentary Mystery，两首都头尾淡入淡出，循环时从头再来；夜里是 OpenMindAudio 的 Night Interior Background – Silent Suspense Underscore（-36），剪成首尾无缝循环。在后座时放哪首看关卡（`ambKey()`）：1～3 关刚入住、周生上门前，日夜都放入住那首（轻一些的日常钢琴）；第 4 关异样夜整关放夜里那首；第 5～12 关按夜里模式或晚上七点后放同一首；第 13 关起（第四次就诊之后的后座夜）改放 Hidden Hypothesis（`环境-后座夜里-后段`），响度对齐前一首。诊室第四次仍是 Tense Sad Piano，不跟后座夜里混用。天台（`环境-天台`）是风声和音乐混成的一个文件：17 秒的 Wind Blowing SFX 01 随机截段、偶尔倒放、交叉淡化拼成 148.5 秒，尾巴再交叉淡化回开头，循环时风不断；上面叠 Reflective Serious Piano (Rain On The Station)，头尾淡出，每轮从头再来。风 -34.5、钢琴 -32、合起来 -30 LUFS。
- 诊室每次就诊换一首音乐（都是 -38 LUFS，头尾淡入淡出）：第 6 关 `环境-澄心诊室`（A Calm Soundtrack for Thoughtful Narration）；第 8、10、12、14 关分别是 `环境-澄心诊室-第8关` 等（Thoughtful Piano Calm、Quiet Suspicions、Tense Sad Piano、Echoes of Mystery）。规则在 `ambKey()`：`AMB_FILES` 里有 `clinic-room-关号` 就用它，没有就用第 6 关那首。
- `assets/sfx/备用/`：挑剩的音乐，游戏不用，留着以后配别的场景；试听页最后一段能听。`assets/sfx/候选/`：还在挑的。
- 试听：打开 [试听.html](试听.html)，所有声音都能单独点来听，音量和游戏里一样。后座的底噪里不放滴水、水管、电视笑声、人声，这些是线索，只在剧情里响。

## 补图

总表：[图/游戏/README.md](../图/游戏/README.md)。图按关卡分文件夹，一个文件只管一处；换图就用新 PNG 覆盖同名文件。

代码里写 `pic(4, "示意-水龙头")`，指 `图/游戏/04-第一夜-8月14日夜/示意-水龙头.png`；随当前关变的底图（对话背景、等待页）用 `lvPic("场景-后座厅")`。头像和地图直接写路径（`"00-通用/头像-周"`、`MAP_PIC + "荣汇街-厅"`）。点热点（`hot()`、关内 `spots`、日历格子）时，那张小图会自动带进接下来打开的弹窗、日记簿单页或当面对白（右上角一张照片），玩家点图就全屏看原图（`ui.js` 的 `withClue`／`zoomPic`）。热点是一个人（周生、陈家豪、表姐来电）就在 spot 上写 `person: true`，对白里不再贴照片。弹窗、日记簿、租盘大图、墙簿相片、地图照片都能点开放大。加新图：先在代码里写好名字，把 PNG 放进对应文件夹，再在总表补一行。缺图时格子里会显示完整路径。

## 壳文案与编码

index.html 只保留 ASCII 结构；顶栏／底栏／地图／日记簿标题等中文由 `assets/core.js` 的 `fillShellChrome()` 写入。不要用编辑器直接往 index.html 里写中文（容易变成 ??）。改措辞只改 `fillShellChrome`。
