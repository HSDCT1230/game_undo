# 暗度 undo

对话解谜。2014 年香港。四个视角看同一场圈套。

| | |
| --- | --- |
| 中文名 | 《暗度》 |
| 英文名 | undo |
| 仓库 | [HSDCT1230/game_undo](https://github.com/HSDCT1230/game_undo) |

灵感来自 2002 港产心理片。策划内部可对照原片结构，对外不使用原片片名和原片人名。

## 目录

```
策划/                  文案与设定（对稿真相源），总索引见 策划/README.md
  设定/                纲要、因果与名词、时间线
  人物/                人物志、关系图
  剧本/                通读故事、分场、关卡、对话分支
    改对话/            改台词入口、口吻全检、DeepSeek 提示
    ink/               第一章 Ink 底稿（不进页面）
  番外/                读者向小说（不做进游戏）
  归档/                已做进游戏的方案，留作记录
图/                    全库唯一图库
  人物/ · 场景/ · 道具/ · 游戏/ · 品牌/
游戏/                  可玩工程（第一章十六关）
  index.html           双击或运行 打开游戏.bat
  assets/              story-* · web-data/ui/i18n · s2hk · style-*
测试入口/              每关一个双击入口（.url），由 tools/做入口.mjs 生成
tools/                 全检、门检、冒烟、手机核对、通关清单、查图、导出对白、ink 检查、做入口
  img/                 全家福、做旧、CCD 等会反复用的图工具
```

## 从哪里开始

| 想做什么 | 看这里 |
| --- | --- |
| 玩 | [游戏/README](游戏/README.md)（`?level=N` 跳关）；只想进某一关，双击 [测试入口](测试入口/README.md) 里那一个 |
| 了解故事 | [故事](策划/剧本/00-故事.md)：主路通读，按日子 |
| 查规则、人名、界面化名 | [策划纲要](策划/设定/00-策划纲要.md) |
| 改台词 | [改对话](策划/剧本/改对话/改对话.md)：关 ↔ 场次 ↔ `story-*.js` |
| 找某份文档、查谁做主 | [策划/README](策划/README.md) |
| 换图、补图 | [图/游戏/README](图/游戏/README.md)：按关分文件夹，覆盖同名 `.jpg` |

改完跑 `node tools/全检.mjs`（全量检验，0 个 ERROR 才算过）；动过关卡表再跑 `node tools/门检.mjs`（查必做项有没有死门）。
想完整验一遍，照 [通关核对清单](策划/剧本/改对话/通关核对清单.md) 点一次流程。
