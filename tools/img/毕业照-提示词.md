# 毕业照底图：提示词与重生成

`图/游戏/15-等他-9月7日夜/示意-家豪毕业照.jpg` = 底图 + `tools/img/毕业照.py` 压边框、印字、做旧。
换底图不改代码，只重跑一次脚本：

```bash
python tools/img/毕业照.py 底图.png            # 底图无水印时，不要传第二个参数
python tools/img/毕业照.py 底图.png 90         # 底图底部有水印要切，传像素数
```

跑完记得改 `游戏/assets/pics.js` 的 `PIC_VER`（换图必须换版本号，否则浏览器吃旧缓存）。

## 2026-10-23 这轮要解决的问题

旧底图三十个人一张脸：同一发型、同一脸型、同一表情、同一机位正对镜头，
缩到 1116×780 再压旧之后，脸只剩一团同质的肉色。要的是：
**在脸只有 30–40px 的情况下还能分出「这是不同的人」**。

小尺寸下靠得住的区分维度，按重要性排：

1. **发型的剪影** —— 寸头、背头、三七分、中分、卷烫、平头、及肩直发、马尾、齐刘海短发、发线后退。
   这是 30px 下最有效的一层，必须拉开。
2. **有没有眼镜 / 镜框粗细** —— 粗黑方框、细金圆框、无框、半框、玳瑁大框。第二有效。
3. **脸型轮廓** —— 圆、方、长、窄、宽颧、重下颌。胖瘦比五官更重要。
4. **肤色与身高** —— 一排人高矮参差、皮色深浅不一，站位才不像复制粘贴。
5. **姿态与表情** —— 有人张嘴笑、有人比 V、有人比心、有人竖拇指、有人只是礼貌笑、有人板着脸。
6. **衬衫与领带** —— 白、浅蓝衬衫；深红、藏青、褐、灰领带。**袍子本身没有颜色差**，
   见下面「2026-10-26 服饰考证」：全院披带必须一个色，靠衣服拉不开人，只能靠脸。

## 提示词（可直接复用）

要点是**把"每个人必须不同"写成一串可执行的具体项**，而不是只说 "diverse"；
另外明确写"虚构人物、不像任何真人"，这是这个项目对他的脸一贯的处理（头像始终是剪影）。

of six crouching on the floor.

All people are entirely fictional and invented, with no resemblance to any real person,

## 2026-10-26 服饰考证（这一批图作废重做就是因为这个）

原来的底图让三十个人分别披红、宝蓝、金、绿四种披带。写提示词时那是**故意的**——
想靠颜色把三十张脸分开。但这是错的，香港的学位袍不是这么穿的：

**学位袍以「学院」为单位定颜色，同届同院同一学位，披带必须完全一样。**
颜色不是个人选择，是学院的标识；个人之间只有衬衫、领带、发型、眼镜、身高的差别。

| 学校 | 本科袍 | 社会科学院的识别色 |
| --- | --- | --- |
| 香港大学 | 黑袍尖袖 + 黑色四方帽（mortar-board） | 兜帽深蓝底 + **深绿丝边 3.5 cm** |
| 香港中文大学 | 黑袍黑绒边 + 四方帽 | 兜帽边 **草绿 sage green** |

港大官方《Academic Dress for Bachelor's Degrees》原文：`Faculty of Social Sciences —
Deep blue with dark green silk edge lining, 3.5 cm wide`（编号 85j）；同页列明理学院是
白边、医学院是红边、法律是古金边，**每院一色，院内无差别**。中大的 Bachelor's Degrees
一栏同样是 `Social Science — Sage green`。

维港大学影射港大（校名取自 Victoria Harbour，港大校服供应商的编码体系就叫
"Victoria Uniform"），所以本作设定为**港大那一套**：黑袍 + 四方帽 + 深蓝兜帽配深绿丝边。

第二处错：**原来三十个人全都没戴四方帽**。港大着装守则里 cap 是固定三件套之一，
毕业礼必戴，帽穗垂在左侧。重做时补上了。

对画面的代价：颜色统一之后，三十个人长得更像了，全靠脸和姿态区分。这跟游戏设定
反而合——第 15 关本来就该是「先看见右下角那行字，才发现这个是他」。
