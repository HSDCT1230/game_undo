# 图

全库唯一图库。策划参考和游戏插图都在这里，不要再往 `策划/` 或 `游戏/assets/` 里堆图。

```
图/
  人物/                 人设参考（游戏不读）
    剧照/               场面肖像 + 编辑页
    全身/               全身站姿
    证件照/             港式 CCD 正面快相
    身份证/             证件成品（贴证件照）
  场景/                 地点结构与实景（游戏不读）
    荣汇街/             28号唐楼平面 + 房间 CCD
  游戏/                 游戏里看得见的每一张图
    README.md           总表：每个文件在哪一关、哪一处出现，画面要求
    00-通用/            头像、倾偈窗口
    00-地图/            地图页的照片
    01-找房-7月31日/    廿八屋租盘、墙簿相册
    02-看房-8月1日/
    …                   每关一个文件夹，按时间线排
    16-天台-9月8日/
    _未接入/            半身原图等，游戏不读
```

| 子目录 | 谁用 | 命名 |
| --- | --- | --- |
| [人物/](人物/) | 对稿、生图对照 | 见 [人物/README.md](人物/README.md) |
| [场景/荣汇街/](场景/荣汇街/) | 案发唐楼结构图 + 房间实景 | `plan-*.png` / `ccd-*.png` |
| [游戏/](游戏/README.md) | `游戏/index.html` 运行时 | `场景-`／`示意-`／`证据-`／`头像-` 加中文名 |

**换游戏里的某一张图：** 在 [游戏/README.md](游戏/README.md) 找到它，用新 PNG 覆盖同名文件即可。一个文件只管一处，换了不会连带别的关。

**人设图不能直接改名丢进 `游戏/`。** 人设按用途分了五类；游戏槽有自己的比例和裁切。对照 `人物/` 另出一张，再覆盖到 `游戏/` 对应文件。`场景/荣汇街/` 的实景要进游戏，也是复制一份到 `游戏/00-地图/` 或某关的文件夹，游戏不读 `场景/`。

游戏读图路径：`游戏/index.html` → `../图/游戏/<文件夹>/<名字>.png`，入口在 `游戏/assets/pics.js`。
