# 图

全库唯一图库。策划参考和游戏插图都在这里，不要再往 `策划/` 或 `游戏/assets/` 里堆图。

```
图/
  人物/                 人设参考
    剧照/               场面肖像 + 编辑页
    全身/               全身站姿
    证件照/             港式 CCD 正面快相
    身份证/             证件成品（贴证件照）
  场景/                 地点结构与实景
    荣汇街/             28号唐楼平面 + 未进游戏的房间 CCD
  游戏/                 游戏内插图（按关分文件夹）
    README.md           总表：每张图用在哪
    00-通用/            头像、倾偈窗口
    00-地图/            地图页照片
    01-找房-7月31日/ … 16-天台-9月8日/
    _未接入/            半身原图等，游戏不读
```

| 子目录 | 谁用 | 命名 |
| --- | --- | --- |
| [人物/](人物/) | 对稿、生图对照 | 见 [人物/README.md](人物/README.md) |
| [场景/荣汇街/](场景/荣汇街/) | 案发唐楼结构图 + 未进槽的房间 | `plan-*.png` / `ccd-*.png` |
| [游戏/](游戏/) | `游戏/index.html` 运行时 | 见 [游戏/README.md](游戏/README.md)；代码用 `pic(关, "名字")` |

**人设图不能直接改名丢进 `游戏/`。** 对照 `人物/` 另出一张，按游戏总表文件名放进对应关的文件夹。

游戏读图：`游戏/assets/pics.js` → `../图/游戏/<关文件夹>/<名字>.png`。
