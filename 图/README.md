# 图

全库唯一图库。策划参考和游戏插图都在这里，不要再往 `策划/` 或 `游戏/assets/` 里堆图。

```
图/
  人物/                 人设参考
    剧照/               场面肖像 + 编辑页
    全身/               全身站姿
    证件照/             港式 CCD 正面快相
    身份证/             证件成品（贴证件照）
  场景/                 地点结构与实景
    荣汇街/             28号唐楼平面 + 未进游戏的房间 CCD
  游戏/                 游戏内槽位
    待补图.md
    01-listing-ssp.png
```

| 子目录 | 谁用 | 命名 |
| --- | --- | --- |
| [人物/](人物/) | 对稿、生图对照 | 见 [人物/README.md](人物/README.md) |
| [场景/荣汇街/](场景/荣汇街/) | 案发唐楼结构图 + 未进槽的房间 | `plan-*.png` / `ccd-*.png` |
| [游戏/](游戏/) | `游戏/index.html` 运行时 | `01-用途-对象.png`，与 `game.js` 的 id 一致 |

**人设图不能直接改名丢进 `游戏/`。** 人设按用途分了五类；游戏槽有自己的比例和裁切。对照 `人物/` 另出一张，按 [游戏/待补图.md](游戏/待补图.md) 的文件名放下。

游戏读图路径：`游戏/index.html` → `../图/游戏/<id>.png`。
