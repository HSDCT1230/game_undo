# App 图标 · A 亮窗·夜

竖长窗＋十字窗棂，四格同亮，暖金渐变压在深蓝黑上。

四格即四人——四个视角看同一扇窗，光是同一场圈套。这是四个方案里唯一
「图像本身就在讲游戏机制」的一个，24px 下也读得出四个格子。

## 出图

```
python _gen/appicon_a.py            # 全套尺寸 + SVG + 场景预览（约 1 分钟）
python _gen/appicon_a.py --sheet    # 另留一张 4096 母版
```

需要 Pillow、numpy（`C:/Users/11356/.workbuddy/binaries/python/envs/default`）。

不是 AI 生图：全部图形是矢量逻辑画在 4096 上（斜边、圆角、渐变都在超采样层算），
最后 LANCZOS 降采样到各尺寸。所以边缘干净、无水印、任何尺寸都能重出。

## 文件

| 文件 | 说明 |
| --- | --- |
| `icon-4096.png` | 母版 |
| `icon-2048/1024/512/256/128/64/32/24.png` | 自母版降采样，不经二次压缩 |
| `icon.svg` | 同几何矢量源，1024 视图；改色改比例可重出 |
| `场景预览.png` | 大图套 22.4% 系统圆角，下排 128/64/48/32/24 深底浅底对照 |

## 参数（改这里就够）

| 项 | 值 | 备注 |
| --- | --- | --- |
| 本体圆角 | 1.1% | 做硬；系统 22.4% 圆角只在预览里套 |
| 窗框外沿 | 0.24–0.76 × 0.13–0.87 | 竖长窗，约占画幅宽 52%、高 74% |
| 窗框金线 | 0.014 | 淡金 `#f3dfb1`，大尺寸才看得见 |
| 框与玻璃暗缝 | 0.005 | 把「框」和「玻璃」分开，小尺寸自动消失 |
| 十字窗棂 | 0.042 | 暗色 `#0b0e14`；居中十字，四格等大 |
| 玻璃渐变 | `#fbeeca → #f1d69d → #d4a25b` | 自上而下，暖金 |
| 四格亮度 | 1.000 / 0.968 / 0.934 / 0.898 | 左上最亮；差值小，仍是「四格同亮」 |
| 窗光外溢 | 半径 0.66，峰值 0.22 | 加法叠在深蓝黑上，让墙「被照亮」而非涂亮 |
| 底色 | `#181d28 → #11141c → #0a0d13` | 取自 `style-base.css` 的 `--night` 系 |

配色基准：`--night #12151c`、`--desk #1b1f28`、`--paper #efe6d6`、暖金 `say-zhou #e4c98a`。
