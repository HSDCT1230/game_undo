## 全作 App 图标 · A 亮窗·夜（定稿）

见子目录 [`App图标-a-亮窗夜/`](App图标-a-亮窗夜/)。竖长窗＋十字窗棂，四格同亮，
暖金渐变压在深蓝黑上。四格即四人——四个视角看同一扇窗，光是同一场圈套。

矢量化工艺：图形逻辑画在 4096 上再 LANCZOS 降采样，不是 AI 生图；本体圆角做硬（1.1%），
系统圆角（22.4%）只在预览里套。生成脚本 `_gen/appicon_a.py`，改色改比例可重出。

| 文件 | 用途 |
| --- | --- |
| `icon-4096/2048/1024/512/256/128/64/32/24.png` | 全套尺寸，自母版无损降采样 |
| `icon.svg` | 同几何矢量源（1024 视图） |
| `场景预览.png` | 22.4% 系统圆角预览＋128/64/48/32/24 深底浅底对照 |

备选方案 B 纸实心、C 纸线描、E 门缝·夜 只在对话里比过，未出图，不入库。
