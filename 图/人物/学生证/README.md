## 重制（2026-10-21）

两张旧卡的证件照做坏了（过曝糊成一团、右下还有一块糊斑），按原版式重做，顺带补了林伟森那张。
旧图原样保留，`-重製` 后缀是新版。

- 生成器：`python tools/img/学生证.py`（`--check` 只量字块，`--only 03` 单出，`--sid-lam` 改林伟森学号）
- 证件照取自 `../证件照/`，做旧走「降采样 → 抬黑压反差 → 暖偏 → 颗粒 → 低质 JPEG」，不套滤镜
- 陈家豪那张用**平光**，跟另外两张同一套处理。侧光试过两版（0.56 硬边、0.42 柔和），
  但他的底色是浅灰，任何横向明暗都会在背景上留一条竖直接缝，看着像裁歪了；平光才真的均匀。
  代价是他的脸比原来清楚，`图/游戏/README.md` 里「他的头像一直是剪影」那条要另外交代
  （已由下方「轮廓版」解决：三张都不给脸）
- 全卡只用一套字：simsun，繁体、数字、英文同一个字面，字重只靠字号与描边分级
  （标题 74／學生證 52／姓名 50／值 36／标签与页脚 30～33；拉丁值 38，比中文大 2，因为它的字母只有 0.7em 高）
- 墨色两档：正文 (44,43,41) 不透明度 238，标签与页脚 216。横条里三处文字同为 (231,222,201)／238
- 版式量自旧卡：卡面 24..1130／44..820，横条 87..205，证件照 62..428／219..738，
  右栏两列（标签墨迹右缘 668、值墨迹左缘 712，行距一律 44），
  五行字顶 258/350/441/533/624，页脚 739
- 横条和证件照之间留 14px 米色卡面，照片顶边不许贴到横条（贴住就像照片上挂了条黑边）
- 标签右对齐、值左对齐，两个列边各成一条直线；四字标签（英文姓名、發行日期）因此不会顶到值
- 林伟森的学号 91024130K 由策划给定，卡上一串可被剧情引用，改之前先问

## 轮廓版（2026-10-21）

三张的证件照一律换成「空相」：米灰相纸上只有一圈黑轮廓，没有五官、没有明暗、线内跟背景同色。
只换相片 —— 卡面、横条、五行字一个像素没动（`build()` 共用，照片那一块分支）。
`python tools/img/学生证.py --outline` 出 `0X-中文名-輪廓.jpg`，原 `-重製` 不动。

- 人形照原始剪影拓：罗、陈取 `../../游戏/00-通用/头像-罗启明.jpg`、`头像-陈家豪.jpg`（对话里那两道人影），
  林伟森从不上镜，从 `../证件照/04-林偉森.png` 抠
- 构图一套：头高占相片 46%、冠顶距上边 8.5%，左右按头中线；肩线由相框切掉，不另画
- 线宽 2.4px、墨 (24,22,20)；边界 = 膨胀减腐蚀取等宽带，再轻模糊、取阈，边缘带一点颗粒，像印上去的
- 背景 (172,171,166)→(146,145,141)，左上一点光；三张同一套，摆一起才像同一批冲的
- 林伟森抠像：背景是浅蓝灰（B 比 R 高 30 上下），人身上没这种冷偏，按「冷偏」分比按亮度差分稳，
  灰衬衫的肩线才留得住。先开后闭：开运算吃掉眼镜腿的两根细横刺，闭运算补耳前那道细缝
- 两个坑：①裁窗越界不能补黑，要复制边 —— 林的肩宽过相框，补黑会在相片中间描出一道横线；
  ②头像阈值只能卡在 40 上下：背景亮度 ~42，抬到 46 背景就跟着进来，整张多出一条横带
- 这一版把 `图/游戏/README.md` 里「陈家豪的脸不能给清楚」那条彻底解决了：三张都没有脸
- 2026-10-21 已按「同步」覆盖进游戏，罗、陈两张证物图现在都是这一版；林伟森那张尚未接剧情热点
