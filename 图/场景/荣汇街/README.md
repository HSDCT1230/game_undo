# 荣汇街 28 号

案发唐楼。2014 年深水埗，楼龄约 50 年，无电梯。周租后座 $3,200，实用约 280 呎，业主自报连公摊约 380 呎。屋里旧、挤、暗，不脏乱：墙是略冷的浅灰，只有发丝裂纹，细马赛克地、深色木家具、铁窗，和租盘走廊同一套。不要涂成米黄，也不要做成青灰。

临街外立面是褪色灰黄批荡，冷气和窗台下有水渍，电线、铁笼、晾衫、单车、胶凳。墙还在，不是整栋掉皮，也不是露砖危楼。

假街名，不要写成真实门牌。

## 整栋

| | |
| --- | --- |
| 层数 | 地下铺 + 1～6 楼 + 天台 |
| 面宽 | 约 16 呎（临荣汇街） |
| 进深 | 约 48 呎（街 → 后巷天井） |
| 层高 | 约 9 呎 6 寸 |
| 交通 | 深水埗站步行约 8 分钟 |

- **地下**：铁闸铺，铺侧一条窄门入公共楼梯。
- **1～6 楼**：每层一前座一后座，中间公共楼梯平台。
- **天台**：水箱、晾衫架、后楼梯出口。无电梯，所以陈要从街底跑六层。
- **公共楼梯**：临天井一侧有铁条窗。
- **后楼梯**：贴后巷，直上天台。住客可用。不经过后座睡房。

## 四楼

周锦荣住**前座**（临街）。章慧琪租**后座**（临天井）。同层隔一道墙。

## 后座（租约范围）

独立厨厕。储物室上锁、钥匙业主收，**不入租**。东门开向后楼梯，南门开向厅，不经过睡房。

内笼 16 呎宽 × 22 呎深（墙中线）。后楼梯贴在东侧外面，不占这 16 呎。实用约 280 呎，是扣掉墙厚之后的数。

```
后天井（南）
┌──────────┬──────────┐
│ 睡房 8×9 │ 厅 8×9   │  窗朝天井
├──────────┼────┬─────┤
│ 厕所 8×6 │    │储物室│  4×7，不入租
│          │ 走廊│     │
├──────────┤    ├─────┤
│ 厨房 8×7 │    │     │  东侧加宽，仍是这一条走廊
│ 西墙小窗 │    │     │
└──────────┴────┴─────┘
双锁门（北）→ 平台          后楼梯在东侧外，宽 3.5 呎
```

窄走廊从双锁门望向南，看见的是厅那扇水渍窗。储物室门在窗的右侧，要侧过身才对着门。租盘图和夜里门底是同一个转角，不是两头走廊。走廊不是一条 4×13 的完整矩形。

| 房间 | 要看见 | 不要 |
| --- | --- | --- |
| 厅 | 旧布沙发、茶几、红玩具车无灰、全家福远景、马赛克地、略冷浅灰墙 | 被子、叠被柜、人脸特写、女鬼 |
| 窄走廊 | 水渍窗、叠被木柜、车在画面边缘 | 构图中心、4K |
| 睡房 | 铁窗、窗台浅色童码水印 | 开窗下雨 |
| 厨房 | 旧龙头、正滴一滴 | 新装修 |
| 厕所 | 细、马赛克、花洒软管 | 脏到不能住 |
| 储物室 | 门锁、门底一道黑；后楼梯侧另有一扇 | 第一周就开门给人看 |
| 前座 | 临街较亮。可以有周自己的全家福 | 红车、叠被柜这些后座道具 |

屋内家人旧物从十二乡村屋搬来，2012 冬起当遗物仓，2014-07-28 才出租。08-15 起储物室才改成道具间。
