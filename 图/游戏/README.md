# 游戏图

游戏里看得见的每一张图都在本目录，按关卡和时间线分文件夹。**想换哪一张，就用新图覆盖同名文件**（文件名不变，后缀统一 `.jpg`），刷新游戏就能看到。

> 图库一律 `.jpg`（2026-10-19 由 PNG 整批转出，193.7MB → 26.7MB）。生图出来的还是 PNG 也没关系——照旧按同名放进来，然后跑一句 `python tools/压图.py`，它会转成 `.jpg` 并把原 `.png` 删掉。忘了跑的话，`node tools/全检.mjs` 会报「图库里有未转换的 PNG」，不会当成缺图悄悄过去。
> 为什么不用 PNG 了：这批图是照片，PNG 存等于完全不压缩；手机首屏原来要拉 10MB，现在 1MB 出头。

- 一个文件只管一处。同一个物件在不同关出现，每关各有一张（起初是同一张图的副本），换一关的不影响别关。
- 文件名前缀：`场景-` 是铺满画面的底图（地点、对话、关卡卡片）；`示意-` 是可点的小图（热点、日历格子）；`证据-` 是日记簿夹页里的图；`头像-` 是说话人头像。
- 缺图时，格子里会写「待补图」和这个文件的路径，照路径放进去就行。
- 放大图下面的配字像相片背面：第一行名称，第二行游戏里的日期。新加 `示意-`／`证据-` 图，要在 `游戏/assets/pics.js` 的 `PIC_CAP` 补一行（日记簿里有的证物自动用日记簿的标题和时间）；漏写或名称里带连字符、编号，全检报错。
- 代码里的写法：`pic(4, "示意-水龙头")` 指 `04-…/示意-水龙头.jpg`；`00-通用/`、`00-地图/` 直接写路径。读图入口在 `游戏/assets/pics.js`。
- 比例：底图 16:9，热点和夹页 4:3，头像和墙簿相册按原图。2014 香港廉价相机感，不要商标、不要女鬼实体、不要二次元。
