# 游戏图

游戏里看得见的每一张图都在本目录，按关卡和时间线分文件夹。**想换哪一张，就用新图覆盖同名文件**（PNG，文件名不变），刷新游戏就能看到。

- 一个文件只管一处。同一个物件在不同关出现，每关各有一张（起初是同一张图的副本），换一关的不影响别关。
- 文件名前缀：`场景-` 是铺满画面的底图（地点、对话、关卡卡片）；`示意-` 是可点的小图（热点、日历格子）；`证据-` 是日记簿夹页里的图；`头像-` 是说话人头像。
- 底图只放「人站在哪里」的场景，不放物件特写。点开线索后，线索图别在左上角，点它看原图；底图不换成线索。在屋里对话时，底图跟着她当时站的房间。
- 缺图时，格子里会写「待补图」和这个文件的路径，照路径放进去就行。
- 代码里的写法：`pic(4, "示意-水龙头")` 指 `04-…/示意-水龙头.png`；`00-通用/`、`00-地图/` 直接写路径。读图入口在 `游戏/assets/pics.js`。
- 比例：底图 16:9，热点和夹页 4:3，头像和墙簿相册按原图。2014 香港廉价相机感，不要商标、不要女鬼实体、不要二次元。
- 案发唐楼的结构图和未进游戏的实景在 [`图/场景/荣汇街/`](../场景/荣汇街/)，人设参考在 [`图/人物/`](../人物/)。那两处是参考，游戏不读。
