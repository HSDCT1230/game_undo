# 待补图：放哪里、在游戏哪一页出现

清单就在本文件。把 PNG 放到**本目录**：

```
图/游戏/<文件名>.png
```

文件名必须和下表完全一致。游戏读 `游戏/index.html` → `../图/游戏/<id>.png`。缺图时格子里写 **待补图 · id**。不要改 `game.js` 里的 id。

人设参考在 [`图/人物/`](../人物/)，对照用，不要改名丢进本目录。荣汇街结构图在 [`图/场景/荣汇街/`](../场景/荣汇街/)。

怎么补：按「出现位置」找到文件名 → 生成 PNG → 丢进本目录 → 打开游戏走到该页。比例：横 16:9，竖 3:4，方 1:1。人物／物件完整入镜，宁可留边。2014 香港廉价相机感。不要商标、不要女鬼实体、不要二次元。

状态：**已放** = 本目录已有 PNG。**未补** = 槽已接进游戏，丢进去立刻能看见。
