## 第一次：夹页／物件（10-11，已实装）

**定案（2026-10-11）**：六项全做；可删的对白一起删／缩；第 2 项月历 9/6 那格写「医生」；第 4 项划掉的那一行保留。五张新图在 `图/游戏/README.md` 标了「（待补）」，图到之前游戏里是灰块，全检只报 WARN。文末「想请你决定的」四问已答，留作记录。

目的：有几处信息现在是靠人物「讲出来」或旁白「交代出来」的。改成玩家自己翻到、看到，对白就能短一点，玩家也会觉得是自己发现的。

原则：

- 只挪「事实」（日期、名字、谁写了什么），不挪「态度」。人物怎么说、怎么躲，仍然留在对白里。
- 每一项都要能**不看也能通关**，看了会多懂一层。
- 不新造界面。全部用游戏里已有的三种做法（见下面「通用做法」）。
- 要补的图都列在每项末尾，进 `图/游戏/待补图.md`。图没到之前，游戏会显示「待补图」灰块，不影响玩。

### 通用做法（每一项都是这三步）

1. **登记一张夹页**：在 `游戏/assets/diary.js` 的 `ITEMS` 里加一条，例如：

   ```js
   "obj-keytag": { kind: "物件", title: "钥匙牌", time: "2014年8月1日", body: "大门　铁闸　天台……", img: pic(2, "证据-钥匙牌"), key: "水喉坏咗拍门" },
   ```

   `kind` 决定它在日记簿里归哪一类（现有：纸、照片、录音、记下、信封、电话、邮件；这次新加「物件」）。`key` 是日记簿里高亮的那半句。

2. **放一个能点的东西**：在那一关的场景（`HUBS.xxx.places[].spots`）里加一张卡：

   ```js
   { title: "钥匙圈", sub: "绑着一块硬纸牌。", img: pic(2, "示意-钥匙圈"),
     seen: () => ev("obj-keytag"),
     go: () => (ev("obj-keytag") ? showClueModal(item("obj-keytag"), { canFile: false }) : keepThen(item("obj-keytag"), backToHub)) },
   ```

   第一次点：弹出夹页，玩家按「夹进日记簿」收下。再点：只看不收。
   如果那一段是对话而不是场景，就在对话里加一个选择（「看一眼」／「不看」），选「看一眼」才 `keepThen(item(...))`。

3. **删或缩对白**（你决定要不要删，见文末第 2 问）。

验收：`node tools/全检.mjs` 0 个错误；无头浏览器把「看」和「不看」两条路各走一遍到结局。

### 现在的问题（第 14 关实测：18 样证物、18 条笔记、7 页）

1. **翻页和分类签打架。** 页码是整本连号（1／7），三个分类签只是跳到某一页。笔记多一行就续出一页「笔记（续）」，只有一句话。
2. **「收集」里混了两种东西。** 「我写的」是能打开来**动手**的纸（四条、屋里的样子、摆在一起、对照纸），下面却是按**媒介**分的证物（照片／录音／纸／记下／电话／物件）。
3. **按媒介分，对不上玩家怎么想。** 玩家记的是「车」「水喉」「门底」「哪一夜」。同一辆车散在三处：照片「出门前的车」、纸「十六号晚」、笔记「车自己转了方向」。
4. **笔记和证物是同一件事写两次。** 笔记「门底下伸出一小截湿脚印」，证物里又有「门底湿脚印」。笔记没有日期，也点不开。
5. **最好玩的几样东西，日记簿里看不到。** 交给罗启明（`handOver`）、分两堆（`sortPiles`）、一周日历（`openWeekCal`）只在剧情里出现一次，做完就消失：交过什么、他回了什么、作业要求，都翻不回来。
6. **作业只是一段话。** 「写时间、车几转、水喉几耐滴一次」和手上已有的证物没有任何连线，玩家不知道自己交不交得齐。
7. **条目只有字。** 照片类证物明明有图，列表里却看不到。也看不出哪几样是这一关新拿到的。

### 建议的结构：三个签，各翻各的

```
今天            东西                 我写的
────            ────                 ──────
这一关要做的     按日期排（默认）      四条
  ○ 必做          8月13日              屋里的样子／搬进来那晚
  ┆ 可做           录音　只有水 ›       摆在一起（第 4 关）
提示              8月15日 凌晨          对照纸（第 9 关）
作业卡              照片　窗台童码 ›     一周日历（第 11 关后）
  ☐ 车几转 ← 已有    · 鞋是干的          交给罗启明（每次复诊一页）
  ☐ 水喉几耐滴       ……                 分两堆（第 8 关后）
这一关新收的      [按物件看：车 / 水喉 /
  （带「新」）      门底 / 窗台 / 人]
```

- **今天**（取代「待办事项」）：目标、必做、可做、提示照旧。作业改成**作业卡**，每条要求后面写清楚手上有没有对应的东西。页底列出这一关新拿到的证物。
- **东西**（取代「收集」和「笔记」）：证物和笔记并进**一条时间线**，按日期分组。证物带 ›，照片类带小缩图；笔记是一行字，不能点。上面一排小签可以切成「按物件看」。
- **我写的**（从「收集」拆出来）：她自己动过手的纸，全部可以重开。再加两样：
  - **交给罗启明**：每次复诊一页，写交了哪几样、他每样回了什么（数据现成：`S.handed` + `HAND_REPLY`）；
  - **分两堆**的结果。
- **翻页**：页码只在一个签里面数（「东西 2／3」），切签就从该签第 1 页开始。仍然不滚动。

### 功能升级（都接在现有机制上）

| # | 做什么 | 接哪里 | 工作量 |
|---|---|---|---|
| A | 页码分签计算；「我写的」独立成签 | `renderDiaryIndex` / `diarySections` | 小 |
| B | 证物和笔记合成时间线，按日期分组 | `note()` 记下 `S.time`；ITEMS 已全部有 `time` | 小 |
| C | 照片类条目加缩图；这一关新拿到的标「新」 | `S.levelMark.ev` 现成 | 小 |
| D | 「交给罗启明」记录页 | `S.handed`、`HAND_REPLY` | 小 |
| E | 作业卡对照：作业每条要求列出对应证物，有就打 ✓ | `HOMEWORK` 拆成条目，每条配证物 id | 中 |

2. **第二批（功能）**：D + E。让复诊那条线在日记簿里看得见、追得到。

### 选中：换掉 outline

原来 `.tool-card.sel` 是 `outline: 2px solid #c47a28; outline-offset: 1px`。

outline 是**浏览器画焦点框用的那个东西**——tab 键选到控件时框住它的样子。放在纸面上，
它读起来是「系统提示：这个控件被选中了」，而不是「她在这一张上做了个记号」。
两道硬线中间空一格，也是控件的样子，不是纸的样子。

（顺便记一笔：这张卡片 `border-radius` 实测是 `0px`，所以「outline 不吃圆角」这条在它身上不成立，
别拿它当理由。真正的理由是上面那一条。）

| 层 | 值 | 作用 |
| --- | --- | --- |
| 贴边 | `0 0 0 2px #c47a28` | 加在 1.5px 边框外面，合计 3.5px 橙，比原来 outline 厚但不飘 |
| 暖光 | `0 0 0 5px rgba(196,122,40,.14)` | 一圈很淡的晕 |
| 投影 | `2px 4px 0 rgba(60,40,20,.16)` | 硬影落回页面，纸被拎起来了 |

竖条放在边框**内侧**（`left: 0; top: 0; bottom: 0`），不往外探：
第一版是 `-1.5px` 往外压，接口处会凸出一个小角，左边比右边粗一截，看着像边框不匀。

她只是把两样摆到一处，不是盖了一个章。

### 一、高亮可放的格＝把答案指给她看

原来的做法是：点一张卡，能放的那几格亮橙、其余格子淡到 0.55（`.picking`）。
看着像「辅助」，实际是把唯一要她判断的东西替她做了——六行两栏十二格，
哪一格能放就是全部答案，亮起来那一刻这张卡已经落位了，她只剩点一下。

去掉 `.picking` 整段（CSS 与 JS 两侧），格子一律等高同色，不预告。

### 二、换成三条通道

| 通道 | 说什么 | 判什么 |
| --- | --- | --- |
| 行头（新） | 车／水龙头／储物室门／窗台／鞋／时间 | 放**哪一行** |
| 栏头（原有） | 头两个礼拜／十五号之后 | 放**哪一边** |
| 放错回话（新） | 见下 | 放错了没有 |

行头是 `COMPARE_ROWS` 每行新加的 `topic` 字段，第三列，右对齐灰字，12.5px。
它只说「这一行讲的是哪件东西」，不说答案——答案在卡片该落哪一边，那件事要靠读卡片上的日子。

放错三种，都贴在**被点的那一格正上方**，同时那格红 700ms（`.compare-slot.bad`）：

- 没选卡就点格：「先点上面一张卡片。」
- 判对了行、判错了栏：「放反了。这一张该放另一边。」
- 行都判错：「不对。这一张不是这一行的。」

「放反」和「放错」分开说，因为前者是半对：她已经认出了这张卡属于哪一行，
只需换一栏；笼统说「不对」她会从头再想一遍。

**提示为什么不能放页面顶部**：对照纸的格子在弹层最底下（y≈585），
`toolSay()` 是 `host.prepend()`——那句话会出现在引导框下面（y≈220），隔着两屏。
她正看着格子，看不见。改成在格子正上方插一个常驻的 `sayBox`（`hidden`），
说的时候显形，配合同一格的红色，两个信号落在同一处。实测 say y=539／grid y=585。

`sayBox.textContent = msg` 不过 `H()`，港繁模式下会漏出简中，要自己包一层 `H(msg)`。

### 三、选中态：一道边加一圈光

`.tool-card.sel` 原来是 `border` ＋ 隔 1px 一道 `outline`——两道平行线圈着同一张纸，
外圈还是直角的。那不是「她做的记号」，那是浏览器画焦点框的样子（跟 `52bf9fb`
那次「摆在一起」踩的是同一个坑，当时按「outline 不吃圆角」解释，实测这张卡
`border-radius: 0`，理由不成立，真正的理由是**它长得像控件状态**）。

现在：贴边一道橙 + `0 0 0 2px` 暖橙（跟 3px 边框连成一条厚边）+ `0 0 0 5px` 很淡的暖光
+ 底下一道硬影 + 上移 2px。hover 收紧成 `:hover:not(.sel)`，否则选中时鼠标一压上去，
边框色被 hover 抢回去，选中态看着「掉了一层」。
