## 一、底图改成跟着句子走

原来 `startTalk(beats, loc, kind, meta)` 里 `hereBg = roomBgNow()`——读的是**舞台此刻铺着什么**。

## 三、两只信封变回同一件东西

`场景-过场-信封角.jpg`（1920×1080，过场）和 `证据-红圈信封.jpg`（1152×864，证物）原来是同一机位的
两次重画：信封宽窄、翻盖朝向、新闻纸露出多少、红圈位置大小全不一样。它们在同一条线上连着出现
（08-16 出门前，过场一格 + 证物一张），差一点就看得出是两件东西。

做法是不再重画：**以证物那张为母图**，过场那张从母图裁 16:9（`crop(0,150,1152,798)` → 1920×1080，
LANCZOS + 轻锐化）。同一张底片，信封、指甲、红圈、地砖都是同一批像素，逻辑上不可能不一致；
两张的取景又有别（过场紧、证物带腿和地面），不会看着像同一张重复放。

母图上拇指正压着红圈上沿——「信封角朝里，像怕你看见」那句台词仍然成立。

## 代码

`CLINIC_WAIT` 八格各加一行 `img`：

```js
{ title: "阿文坐过的那张椅", sub: "刚起身。垫子还凹着。", img: () => pic(8, "示意-阿文的椅子"), … }
{ title: "洗手间的门",     sub: "水开了很久。",         img: () => pic(10, "示意-洗手间的门"), … }
{ title: "前台姑娘",       sub: "她认得我。", person: true, img: () => pic(12, "示意-前台姑娘"), … }
```

`img` 一给，`hot()` 就会画出 `.hot-img`，点开时 `withClue(imgId)` 把它当放大图，
`PIC_CAP` 里的名称和日期出现在点图放大的说明上。所以三组配字也一并补了：

```js
8:  { time: "2014年8月23日 15:55", "示意-阿文的椅子": "阿文的椅子", … }
10: { time: "2014年8月30日 15:55", "示意-洗手间的门": "洗手间的门", … }
12: { … "示意-前台姑娘": "前台姑娘", "示意-前台的杂志": "前台的杂志" }
```

`tools/门外核对.cjs` 里 `WANT` 的 visit4 底图从 `场景-候诊` 改成 `场景-前台`，
并加了一条：「三个看点必须都有缩图」。这八格当初就是这么漏掉的，加断言才不会再漏。

# 第三轮（10-27）：八月十四傍晚那张重做

## 起因

上一轮把周的脸「改成阳光色的光」——实际做成了贴在脸上的一个发白圆饼，比原来的黑挡板更假；
去杆那一步也把他的头发修成了一顶蓬松的假发。用户看截图后要求重做。

## 结论：不是改坏了细节，是思路错了

分镜原本写的是「门口站着他半身剪影（背光，看不清脸）」。
真实逆光照片里，脸之所以看不出，是因为没曝光，不是因为被什么盖住。
所以不贴遮挡物，改用两件事：

1. **构图把逆光补上**：让它把身后的楼梯间天光画亮，人整个落在暗部；
2. **后期只压头部曝光**（不改造型、不贴色块、不加圆斑）——现在脸是暗褐色，眼睛鼻子只剩起伏。

另外两处原来不成立的：

- **头顶贴边**。这格是 `push: true`，`cut-push` 从 1 倍推到 1.08 倍，
  原来 `origin: "52% 40%"` 锚点偏高，推到最后会把头发切掉。改成 `"52% 30%"`。
  分镜里「静止定格也完全可以」，真到推镜切头，宁可改锚点。
- **字幕压信封**。字幕在 `bottom: 14%`，信封若搁在 80% 上下就会被盖住。
  这一版信封落在 62%–72%，字幕在它下面，不打架。生成时就写了这条约束。

# 第四轮（10-27）：维港大学官网重做

## 起因

> 「http://www.vhu.edu.hk/ 大学官网做得更像真实的大学官网一样，可以参照港大的官网，
> 如有缺图你可以自己生图，不要做得太假太AI味」

## 诊断

不像真站的原因不是配色，是**一整页没有一张照片**：主视觉是纯 CSS 渐变加一个半透明的「1962」水印字。
2014 年那些大学首页靠的是横幅照片、新闻缩图、三格掠影撑起来的，文字只占三成。
所以这一轮不是调色，是补影像、补版式。

## 结构（照着 2014 年港大首页那一套）

```
深青细条（地址 + 简／繁／英）
校徽 + 校名 + 站内搜寻
导航八项 …………………… 右端「教职员内联网」
首图轮播（两张，圆点换图，右下页码）
眉头三块（入学／研究／校友）
左：新闻与活动（缩图 + 标题 + 栏目日期）  右：即将举行（日期块）+「支持维大」
校园掠影三格
页脚四列（校名地址／快速连结／到访维大／关于本站）+ 版权行
```

# 附（10-27）：那两格「杂志」的图文对不上

补八格缩图那一轮之后留下的问题：第 8 关「茶几上的杂志」和第 12 关「搁在前台的杂志」，

## 为什么改字

这两格的字只有 `sub` 一句加弹窗一段，改字零成本；重生成图要重跑裁切、bump `PIC_VER`、

| 位置 | 原来 | 现在 |

| 8 `sub` | 三本，全部倒着。 | 三本，都摊着。 |

# 第七轮：导航第一格放「首页」（2026-10-28）

## 起因

「维港大学默认首页现在是『新闻与活动』这个很不科学，首页应该放在第一页」。

## 病因：首页没有自己的名字，只好借别人的

三件事叠在一起：

1. 导航八项里**没有「首页」**，第一格就是「关于维大」。
2. 「新闻与活动」那一格的 `k` 是 `"news"`，而 `vhuSiteNav()` 里写着
   `if (it.k === "news") goWeb("vhusite")`——它指的是首页本身（新闻区就在首页上）。
3. 首页调用的是 `vhuSiteNav("news")`，于是「当前栏目」的金线压在「新闻与活动」上。

三条都对得上「新闻是首页的内容」，合起来就成了「这台机器只有新闻，没有门厅」。
打开一部大学官网，第一眼该看到的是校门，不是公告栏。

## 改法

- `VHU_SITE_NAV` 前面加 `{ k: "home", t: "首页" }`，导航变成九格
  （研究／校友／捐赠仍是死字，不动）。
- `vhuSiteNav()` 不再给 `news` 开特例：`home` 回 `vhusite`，其余一律落 `vhusite-page`。
- 首页改调 `vhuSiteNav("home")`——金线压在第一格。
- **「新闻与活动」必须变成真的一页**，否则「首页」和「新闻与活动」指向同一个页面，
  点后者既不换页、金线也不动，比原来更怪。

## 「新闻与活动」栏目页

`VHU_SITE_PAGES.news`（`lists: true`），地址 `/news/`，标题「新闻与活动」。

- 一栏到底：导语 → 「本年度已发出新闻稿二十九篇，本页列出最近三条」（解释为什么只有三条，
  这也是旧站的样子）→「新闻稿」三条 →「即将举行」三条。
- 版式跟首页**不一样**：首页是左新闻右活动两栏并排，这里一前一后，读起来是归档目录，
  不是把首页再读一遍。
- 首页那两条列表抽成 `vhuNewsList()`／`vhuEventList()`，首页与栏目页共用同一份 DOM。
  日期、标题、缩图不会再走样成两份。

## 一、四张图错在三件事上

| | 旧版 | 问题 |
| --- | --- | --- |
| 构图 | 整只抽屉拉出来，节拍器摊平摆在正中间 | 正文一直写「没推严」「缝还开着一点」「缝里」，图是**全开**。看图和读字是两件事 |

## 四、文案：他这时还没开口

   结果反而与母图不一致——把母图尽头的门放大（`_scan/corr_door_zoom.png`）才看清：**母图那扇门本来就是
   两块板**。第二版作废，用回第一版。判据：**「母图上到底是什么样」要去量放大图，不要凭印象。**
2. **夜间版连错三版。** 第 1 版 mean 11.0（过暗、全糊）；第 2 版灯管还亮着；第 3 版把遮罩画在
   x 555–745，而灯管在 1920 坐标下实际在 x≈1017–1151——是逐列取最大值（`colmax`）量出来的，
   眼睛估的位置差了一倍。第 4 版才对。

### 四、判据

- **地图里两个相邻的格子不能共用一张照片。** 详情图只有 255px 宽，任何「同一张图涂改一处」的做法，
  在玩家眼里都是「点哪一格都一样」，等于这两格没有图。共用母图是对的，共用**成品**是错的：
  同源可以，同图不行——派生要换景别（全景 vs 近景），不是换一处涂改。
- **「同一张」先量差分再说话。** 平均差、`pct>30`、差分外接框三个数一起看：外接框框住哪个角落，
  就说明改的是那一处，问题也就在那一处。
- **地图图要和「厅」这类邻居对得上。** 走廊右侧的门通的是厅，那门里就得是厅的样子；
  画成另一间客厅，玩家会以为这栋楼多一间房。
- **图注会跟着旧图一起过期。** `README` 原来把这两张写成两处不同景别（走廊「右侧开口通厅」／
  储物室「走廊尽头整扇门…左边木柜叠被」），而实际是同一张——储物室那张**根本没有木柜**。
  这次三行图注重写，并把「走廊一族四张同源」写进「同一地点共用一张母图」那条。
