## 第五关前那通电话：陈家豪介绍阿明

### 原句

> 系。佢肯听。我介绍，佢会收。你同佢讲真话。佢听完会揽晒上身。所以你……准时到就得。
> 楼下嗰间面档，佢有时会唔记得食。

玩家看到的问题：**埋线太刻意**。

拆开看，是三处毛病叠在一起：

1. **四个短句全是「他怎样」**。他肯听／他会收／他会揽／他忘了吃。主语一换再换，句式不变，
   读起来不是一个人在电话里讲话，是在念人物简介。
2. **「佢听完会揽晒上身」把底牌亮了**。这是罗启明这条线最深的一层——他会替人担、会把别人的事
   当成自己的债。玩家要到诊所里、到后面那几次「他没有写病」才慢慢摸出来。提前一句讲明，
   后面就没有「发现」，只剩「验证」。
3. **末尾那句面档是硬接的**。前面四句排比走完，忽然一句「楼下那间面档」——读者一眼看出这是
   作者塞进来的道具，不是这个人顺口会说的话。而且「楼下」指诊所楼下，电话这头的人不知道是哪栋楼。

### 现在

> 系。我识佢十几年，有事都系搵佢。佢唔会问你点解，净系问你食咗饭未。你照直讲就得，
> 唔好同佢客气——你讲一句，佢会当成自己嘅事去做。忙起上嚟，诊所楼下嗰间面档，都要我打电话去叫。

四件事换了位置：

| 原来 | 现在 | 为什么 |
| --- | --- | --- |
| 「他肯听」 | 「我认识他十几年，有事都找他」 | 先回答她上一句的刺（「就是那个你老拿他当借口的？」）。认下来，还顺手解释了为什么值得拿他当借口 |
| 「你跟他说真话」 | 「他不会问你为什么，只问你吃饭了没有」 | 同样是「照直讲」，但换成一个具体动作。不追问、先问吃饭——人物一句话就立住了，也顺手接住了整局「吃饭＝还撑得住」这条线 |
| 「他听完会全往自己身上揽」 | 「你说一句，他会当成自己的事去做」 | 从**结论**退成**现象**。玩家听到的是「这人太当真」，不是「这人会替你担责」。底牌还在，但没翻 |
| 「楼下那间面档，他有时候会忘了吃」 | 「忙起来，诊所楼下那间面档，都得我打电话去叫」 | 同一件事，改成家豪的抱怨（我得打电话去叫他吃）。是他在照顾阿明的证据，不是给玩家的道具。也把「哪栋楼」说清了 |

「你当我没说」那句（下一条）没动。它同样是埋线，但埋法不同：先说好话（专业、用心），
再压低声音补一句，最后自己收回去。这是**人物在下意识护人**，不是作者在交代设定。

## 旁白里的「没有接」「停住」（2026-10-26）

### 一、问题

有一批旁白在拿「否定式动作」代替反应：

> 他没有接。／他没有接话。／她停住。／他停在门口。／他浅浅地笑了一下。

中文口语里没人这么说。人真的没话说的时候，写的是「他没说话」「他没往下说」「他站住了」。
「没有接」是从英文 "he didn't take it"／"didn't pick it up" 直搬过来的，
「浅浅地笑」是形容词叠字翻译腔。这类句子放在一个 2014 年香港旧楼的故事里，最先露馅。

### 二、怎么改

原则只有一条：**写他做了什么，不写他没做什么**。否定式只在真的需要「没做」这个信息时才用
（「他没回头」——她要看的就是他有没有回头）。

| 原文 | 改成 |
| --- | --- |
| 他没有接。 | 他没说话。 |
| 他没有接话。笔尖在纸上顿了一下。 | 他没说话。笔尖在纸上停了一下。 |
| 他端着水，看了一眼你掌心，没有接。 | ……看了一眼你掌心，没伸手。 |
| 她停住，手指在膝盖上捏了一下。 | 她没往下说。手指在膝盖上捏了一下。 |
| 他停住，没有回头。 | 他站住了，没回头。 |
| 只看见他停在那里。 | 只看见他站在那儿。 |
| 他停在门口。 | 他在门口站住。 |
| 他整个人僵住。 | 他整个人定住了。 |
| 他浅浅地笑了一下。 | 他笑了一下，还是那种客气。 |
| 他没有追问，也没有说「节哀」。 | 他没接着问，也没提「节哀」。 |
| 他的视线在你的衫领停了一下。 | 他的视线在你衬衫领子上扫了一下。 |
| 声音是裂的，没有摔门走成。 | 声音是裂的，门到底没摔。 |
| 车停在荣汇街楼下。 | 不动（「停」是真的停，不是悬置） |

「没有」一律收成「没」，除了需要重读的地方（「他没有立刻离开，看着走廊尽头」保留一个，
因为那句的重音落在「立刻」）。全篇改 30 处，另有 3 处「又松开」同构动作删掉 1 处。

### 三、连带：两个繁化错误

改完在粤语模式截图，发现两句更严重的东西：

- **「他只问过一句」显示成「他隻問過一句」。** `s2hk.js` 的 `S2HK_FIX` 里写着 `"只": "隻"`，
  再靠一张副词白名单（只是／只有／只好／只能…）兜回来。白名单是开放类，永远列不全。
  改成反过来：默认「只」保留，量词（一只／两只／那只／这只／几只／每只／哪只…）逐个列进词表——
  量词是封闭类，列得完。
- **「视线」显示成「視綫」。** `'线':'綫'` 是笔误，注释里自己写的都是「前線」。
  港繁标准是「線」。改 `'线':'線'`，同一行的 `'缐'` 一并改。

## 第 1 关 周先生的回复：删到只剩一句（2026-10-28）

原：「今日下昼得。我喺度等。简介写过屋内有旧嘢，你见过怕就同我讲，相可以收起一部分。」
改：「今日下昼得。我喺度等。」

三条理由：

1. **同一件事讲两遍。** 放盘页本来就写着「屋内仍有家人旧物，不介意者优先」，
   留言里再交代一遍，是拿消息重复页面。
2. **把后面的戏提前讲完。** 看房时他当面也说这句（「你个留言我睇咗。旧嘢你怕，就同我讲。」）。
   留言里先说一遍，见面那句就成了复读——而且活的那一句该在门口，不在收件箱。
3. **不像他。** 「相可以收起一部分」是替租客想得太周到。这个人说话短、不解释；
   回一句「我喺度等」就够，冷得像在确认时间，反而更像他。

「我的纸」那条连带改：撤掉旧嘢与相，「周先生回了留言。今日下昼，他在。」
写进纸上的只该是能用的东西（几点、在哪），不该是替她分析对方的心理。

另修一处文档笔误：剧本 `01-第一章-章慧琪.md` 引这句时写作「听日下昼得」，
但回复是 08-01 09:12 发出、当天 15:20 看房，是「今日」。游戏里一直作「今日」，是文档抄错。

## 全剧三类复查：重复、提前剧透、人设不符（2026-10-28）

起因是周先生那条留言：一句话里同时犯了三个毛病。既然它不是孤例，就把三份对白（早期／初诊／后期）、
收件箱与墙簿、报纸与维基、官网新闻稿全部过了一遍，另写脚本做了两轮机器比对
（全句 2-gram 覆盖率 ≥0.62、旁白与紧邻台词 ≥0.45），人工再逐条判。

### 机器比对找出的 17 对里，14 对不是问题

先说清楚什么叫「不是问题」，免得下一轮有人照着改坏：

| 情形 | 例子 | 为什么不改 |
| --- | --- | --- |
| 互斥分支 | 「阿琪？美娟叫我打俾你…」两句只差半句 | 玩家只会遇到一条，各写各的才对 |
| 三种结局 | 「风声空了一拍…竹棚…人卡在棚上」 | 家豪翻出去／阿明掉下去，各写一遍 |
| 刻意的母题 | 「你一伸手，我会以为你拣咗我」出现两次 | 楼梯口一次、天台一次，第二遍是他自己记得 |
| 她的固定说法 | 「我冇问题……有问题嘅系间屋」 | 这是这个人的口头禅，反复才是人 |
| 回收伏笔 | 8/16、8/23、9/6 三格，第 11 关看过、第 15 关原样递过去 | 她记的就是这一句，原样递才对 |
| 证据与记录 | 校报「二〇〇四年十一月…」与纸上那一行 | 纸上记的就是网页上的事实 |

### 真改的七处

**1. 家豪把车祸讲了两遍（早期）**

那句台词先把「精神唔太好／出过车祸／你当我冇讲」一口气说完，玩家再选「『不太好』是什么意思」，
得到的又是车祸。改成电话里只说「佢本人精神有时唔太好。你当我冇讲。睇病人一流。」——
停在半句，追问才吐出「失眠，健忘，接唔上琴日——车祸之后就咁」。
不追问的人，第十九关也会从他嘴里听到「车祸」，不会漏。

**2. 周在收租半月后又复述一遍「重建未轮到」（早期）**

收租那天他已经说过，她还追着问过，旁白也点了「讲到自己都信」。半个月后再原样说第三遍，
没有新东西。现在只留「有咩唔妥就拍门，唔使客气。你安心住。」
——反而不提更可疑：他已经知道有人在查。

**3. 旁白替他看了一遍，他开口又说一遍（初诊）**

「纸上『离开两分钟』那句他看了很久。圆珠笔停在空白处，没落下去。」紧接台词
「我睇咗好耐。支笔吊喺半空，冇落到。」同一动作说两次，而且台词更狠。
删旁白，留他的嘴；末尾「诊室听唔到门底」也删，下一句「我喺度听唔到，就唔可以帮你写实」已经说了。

**4. 上门那条界线讲了四遍（初诊）**

1752「观察，唔算治疗」→ 1766「观察唔等于治疗…要知情同意…知情同意即系…」→
1767「唔系陪你过夜。唔系开药。唔系证明有鬼」→ 1808「唔经门诊预约。唔带药。唔过夜」→
1839「只听门底，唔算治疗，唔过夜」。

保留 1766（正式交代）与 1767（三个「唔系」，最像他），其余三处收掉：
1752 只留「唔系嚟令你开心」；1766 删「要知情同意」与「知情同意即系」（术语先报一次再解释一次）；
1808 只留真正要在门外敲定的「周先生知唔知你叫我嚟」；1839 收成「条界仲喺度：我只系听门底」。

**5. 「家豪叫我唔好查业主」说了三遍（初诊）**

第一次会诊介绍身边人时一次、第二次会诊回顾车里那句一次、第三次又答一次。
第三次删掉重复那半句，只留「佢上次讲完就走」——问的是他有没有再打来，她答的也是这个。

**6. 两个选项的第一句都在复述主干（第 13 关争吵）**

主干刚说完「讲得几好听，都系当我病人」，选项一又「你用好听嘅字。骨子里都系觉得，有问题嘅系我」。
按既定的选择尺子，选项后该是**只属于这条选项**的话：删掉那句，只留
「佢哋煲汤叫我食药。你写安全行为。字唔同。我听落一样。」（她把他并进表姐、阿乐那一列）。
选项二同理，删掉重复的「我等咗三个礼拜六」，留只有它才有的那两天。

**7. 网页正文里混进了她的判读（资料页）**

罗启明的诊所名录正文末尾写着「没有二〇〇四年，没有十一月，没有女学生」；
校报旧闻末尾写着「公开的罗启明履历，从这一月直接跳到毕业」。
这两句都不是网页上会有的字，是她读完在心里数的——而「我的纸」里本来就各有一行同样的。
删。留事实：名录写到「公开页到此为止」，校报写到「其后没有跟进报道」。
玩家把两页摆在一起，中间空的那一年自己会对出来；替她说完，反而夺了这一步。

### 顺手修的一处事实冲突

同一份「旧楼重建与健康」研究，官网新闻稿写「访问一千二百户」，
《香港日报》写「访问四百二十户，其中一百七十户搬迁」。两边都读得到，撞上就露。
官网改从报纸那个数（报纸更细，且带搬迁户数）。

### 判据（写下来给下一轮用）

- **同一个事实，先问它有没有第二个人需要知道。** 需要（如证据进纸）就留，两处措辞要不同；
  不需要（如他反复保证同一件事）就只留信息量最大的那一遍。
- **旁白只写她看见的；角色的结论让角色自己说。** 旁白替他说完，他说的时候就成了复读。
- **留白比说满更贵。** 车祸从电话里挪到追问后面，第 19 关他自己说破时才有分量。
- **复述不等于重复。** 她向医生汇报观察到的东西，逐字一样是对的（她记的就是那一句）；
  他向她重申自己守的界线，逐字一样就是话本写懒了。

## 旁白：教程腔、替她下的结论、复述（2026-10-28）

### 一、起因

> 终于有人肯听。我把东西都装进袋里，出门时抱在腿上，像要去认错。
> ……这些表述还是不符合日常说话的习惯。其他的旁白部分也修改一下，不要太啰嗦说废话，
> 过度自我表达，要准确、生动、直白、但又充满吸引力。

三处毛病：**「袋里」是书面缩略**（人说话讲「袋子里」）；**「肯听。」用句号切断**，
像电报，不像一口气说完；**「像要去认错」是作者替她补的比喻**——她已经抱在腿上了，
那点心虚在动作里就有，再点破一次，读者只剩「哦，原来是这样」。

改成：

> 终于有人肯听了，我把东西都装进袋子里，出门时抱在腿上。

- 旁白里混进粤语名词：`一竿晒干的衫`／`抱着衫往下走`／`抓住他的衫袖` → 衣服／袖子。

### 三、判据（给下一轮用）

- **旁白里不出现第二人称的教程句。**「你可以……」「你还没有……」这类，改由物件自己点名
  （热点副标题），不长在叙述里。
- **一句旁白只做一件事**：给画面，或者给动作。给了画面又替她解释这个画面的意思，
  就是把玩家该走的那一步拿走了。
- **关头与目标分工**：一个心情，一个方向。
- **同一个收束句全篇只用一次。** 第二次要留，就得换个说法。
- **旁白用「你」，她的日记用「我」。** 除了引语，旁白出现「我」就是把日记腔串进叙述。
- **缩略看语感不看字数。**「袋里」少一个字，但没人这么说话；「袋子里」才是人在讲。

用户：「AI 味太浓，『追』这个词很容易造成玩家困惑以为要跟着周房东跑出去，建议最后一个选项直接改成

### 那一个为什么错

「他已经转身。你还要约四点的诊。」底下是 `不追。先记下这一幕。`——
四个选项里前三个都落在具体东西上（看信封／发生什么事／我可以晚一点走），只有最后一条是个**否定 + 抽象**。
「追」这个词本身带着画面：玩家读到它，先想的是「跑下楼跟着他」，然后才读到「不」。
而这一格真正发生的事只有一件——她不出声，把刚才看见的收起来。
