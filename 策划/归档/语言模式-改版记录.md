# 语言三档：把「粤＋普」挪到「普＋粤」（2026-10-30）

> 方案见 `策划/语言模式-合并方案.md`（§3 方案 A）。这篇记的是实施时真正改了什么、
> 拍了什么、哪里和方案不一样。
>
> 作者拍板三件事：**旁白不算对话，归普通话单行**；**对白保持「粤语主行 ＋ 普通话小字」**；
> **先保留三档，只改「粤＋普」的语义**。

## 1 原来的毛病：一个按钮里挤了两件事

三档其实是「正文语言 × 对白是否加对照」的组合，但「粤＋普」同时占着两格：

| | 正文 | 对白 | 玩家记得住吗 |
| --- | --- | --- | --- |
| 粤语 | 粤语 | 单行 | 记得住 |
| 粤＋普（旧） | **粤语** | 双行 | 记不住：正文跟「粤语」一样，只多一行小字 |
| 普通话 | 普通话 | 单行 | 记得住 |
| （普, 是） | 普通话 | 双行 | **空着** |

空着的那一格才是真正需要的：「正文我看普通话，但人物说的话我要听原声」。

## 2 改完是什么样

| | 顶栏／网页／簿子／卡片／聊天 | 旁白 | 角色对白 |
| --- | --- | --- | --- |
| 粤语 | 港繁粤语 | 港繁 | 港繁粤语，单行 |
| **普＋粤** | **简体普通话** | **简体普通话，单行** | **港繁粤语主行 ＋ 简体普通话小字** |
| 普通话 | 简体普通话 | 简体普通话 | 简体普通话，单行 |

判据一句话：**她「听到的」用粤语；她「看到」「想到」的用普通话。**

这条判据顺手解释了两件早就有的事：聊天窗口为什么不加双行（她低头读的，不是听见的）；语音留言为什么算「听到的」。

### 3.1 唯一的技术难点：`yueFace` 一件两用

`yueFace(s) = H(s)` 同时被两种东西用着——

- **对白**（`faceLine` 里那一处）：普＋粤下必须是港繁粤语；
- **界面词**（挂断／静音／听下句／你说／短讯等 17 处）：普＋粤下应当跟普通话走。

`H()` 一旦在 both 下变普通话，对白会被一起翻译，双轨就变成**两行一模一样的普通话**。所以拆出 `faceYue()` 专供对白主行，界面词保持 `yueFace()`。

**自检办法**：切到「普＋粤」，看一句角色话——第二行必须与第一行不同，且第一行有「唔／嘅／咗」。`冒烟` 抓不到这一类（它不比对两行是否相同）。

### 3.2 旁白为什么要一个 `as` 参数

旁白和角色话走同一个 `faceLine`，区别只在「谁说的」。`as` 传值：

- 不传：她听到的原话 → 港繁粤语（三种模式里两种都是它）
- `"narr"`：旁白、选项提示 → both／zh 取普通话
- `"read"`：短讯气泡 → 同上（她低头读的字）

判据写进代码注释，不靠调用者记。

## 4 顺带查出的三个错

1. **两条旁白在普＋粤下露粤语**：`story-clinic.js` 里「那行字写的是「瞓唔好。靠人靠得深。冇计划。」」、`story-late.js` 里「表姐叫过你中秋返去食饭」。两条都没有 `{ zh }`，`zhOf()` 也整串查不到。各补一条 `zh`。
2. **选项夹粤语**：85 条 label 里 3 条带粤语词，其中 1 条早在表里，另 2 条（「我怕我一说，你心入面就有数。」「我讲得慢，你等得就等。」）本轮补进 `yue-zh.js`。不补的话 both／zh 下会显示成「简体字 ＋ 粤语词」，比港繁更像错字。
3. **注释过时**：`core.js` 两处、`talk.js` 两处、`web-vhu.js` 一处原本写着「粤＋普转港繁」，改完就错了，一并改。`web-vhu.js` 那句说的是「有人会照屏幕上的字打繁体」，改成「只有粤语模式是港繁」，`vhuAnsNorm` 的「不认繁简」逻辑本身不动（它两头都归一）。

顺手把规范 §0 必跑表里「图片 198 张」删掉——数字会变，以脚本输出为准。

## 6 `tools/扫粤语.mjs`：两档比较而不是扫繁体

一开始想按「含繁体字」判断漏译，写出来满屏误报：`toHkTrad("日记簿") !== "日记簿"`，简体本来就会被转，判据反了。

改成**同一屏分别在普＋粤与普通话下渲染，逐节点比较**：

- 两档文本不一致 → 普＋粤没跟普通话走（**对白主行除外**，它本来就该是粤语）；
- 两档一致但带粤语词 → 对照表缺条目，两档一起漏（这也是 `zh` 档一直漏的那批）。

第一版跑出来只有顶栏按钮那一格「不同」——那是设计如此。8 个屏（hub／网页首页／盘源／讨论区／新闻／VHU 官网／簿子／地图）、合计 0 漏译、0 缺表条目。

## 7 已知项：图上的字不会跟着变

both／zh 下 UI 是简体，烧在图里的汉字仍是繁体（港式手写本来就该是繁体，不算错，但要说清楚）。按 `图/游戏/README.md` 逐条清点，会被读到的有：

| 图 | 图上的字 | 会不会被读到 |
| --- | --- | --- |
| `证据-周的月历` | 8/1 后座入伙…9/6 六　醫生 | **会**（日期是她对时间线的核心证物） |
| `证据-笔记一页` | 9/6 21:52／水喉：拧紧后约 3 秒再滴… | **会** |
| `示意-日历-0810-交租` | 後座 章小姐／8/1 按金 收… | 会（但正文有同一份信息） |
| `证据-钥匙牌` | 大门　铁闸　天台… | 会（正文与簿子都有） |
| `证据-全家福背面` | 丽芬　阿轩　十二乡村屋门口　二〇一二年春 | 会 |
| `示意-预约表` | 預約表 | 低（数量关系在正文里） |
| `示意-抽屉缝` | 只能看见「……转介」两字 | 低 |
| `示意-家豪毕业照` | 相角 `陳家豪　01038472H` | **会**（那条路唯一的学号来源） |
| `证据-鱼牌` | 无字 | 不用管 |

处理原则（同「图跟正文对得上」的老规矩）：**能改正文拿到信息的就先改正文，图只作氛围**；正文已经说过一遍的（日历、钥匙牌）不必重画。真要重画，得等生图额度恢复。

## 8 没做／留给下一次

- **没删「普通话」档**。删档要迁移 `undo-lang-v3` 的老值（老的 `both` 会回退成全粤语），且「一行粤语都不想看」的玩家会失去选择。方案 §7 有删减版，随时可做。
- **对白主行仍是港繁**（繁简同屏）。这是「听到粤语」的直接结果，字号／颜色／位置三样都不同，实拍确认不打架。要全简体的话，`faceYue()` 改成不做港繁即可，代价是粤语只剩用词、`toHkTrad` 的词组映射（的士／巴士）也不再生效。
- **图上繁体字**：见 §7，等生图额度。
