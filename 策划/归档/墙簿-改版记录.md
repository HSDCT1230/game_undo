# 墙簿改版记录（已实装，存档）

2026-10-30 一次改版。现状以代码为准：`游戏/assets/web-data.js`（`WALL_FEED`／`WALL_MAIL`／`WALL_NOTICE`）、`web-ui.js`（`viewWall`／`wallNoticeBar`／`viewWallMail`／`wallMailThreads`）。

---
## 起因

玩家（也是我自己）翻墙簿时的第一反应是「这页为什么有这条」：

- 「你今晚住边。沙发留住。」挂在**公开首页**上。表姐不会在墙上问这种话——那是给旁人看的。
- 廿八屋的「你收藏的楼盘已标记为已租」混在**收件箱**里，和表姐、阿乐的话排成一列。它不是人说的。
- 两个页面长得**一模一样**：都是一列卡片、都有「回应」。所以「这句在这边、那句在那边」看上去像随手放的。
- 左下角「墙簿 (2)」和标签页「收件箱 (2)」是同一批未读，被数了两遍。

## 定案（方案 A：按「谁看得见」重划）

一句话：**首页＝对所有人说；收件箱＝只跟一个人说；通知不是人说的，单独一条。**

1. 首页只留公开的话：家常、饭菜、加班、照片。
2. 收件箱只收「单独发给她」的话，**按人分栏**，右边是一来一回的对话。
3. 廿八屋那条搬去首页顶上一横灰条（无头像、无「回应」、不算未读）。
4. 两个页面长成不同形状：首页按时间（帖子流），收件箱按人（左人右话）。
5. 修掉未读数数两遍。

### 三条判据（以后往墙簿加东西照这个分）

- **这句话若被第三个人看见，说话的人会不会改口？** 会 → 收件箱。表姐在墙上从不点名问私事，这是她自己那套体面；阿乐更不肯在墙上说。
- **有没有一个「人」在说？** 没有（平台、系统）→ 通知条。
- **形状不同，玩家就不会再问**「这句为什么在这边」。同类东西放到一起还不够，两个页面得长得不一样。

### 为什么首页要有生活照

公开页如果只有字，和私信的区别只剩「一栏还是两栏」。要让人一眼看出「这是给别人看的」，最省的办法是**照片**——朋友圈那种：拍了就发，不修、不构图。

所以补了 6 张生活照，尺子写进 `图/游戏/README.md`：手机 CCD 随手拍，硬闪光、偏黄绿、四角略糊、可能过曝，没人摆位、没人入镜。首页按 340 宽显示，点开是同一张放大。

**改版真正想拿到的效果**是表姐变成两副面孔：墙上说家常（位子一直留、煲了汤、月饼买了两盒），私信里说担心（你今晚住边、我等到一点、电话入面成日有水声、今个星期六真的再去）。以前这些话混在一栏里，读起来是同一个声音。

## 代码落点

- `web-data.js`：表头注释写死分类规矩；`WALL_NOTICE` 与 `WALL_MAIL` 分开。
- `web-ui.js`：`wallNoticeBar()` 只画标签、时间、正文；`viewWall()` 把通知条塞进 `.wall-main` 顶部；`viewWallMail()` 重写成 `.wall-mail-split`（左 `.wall-msg-list`／右 `.wall-thread`），新增 `wallMailThreads()`、`wallThreadKeys()`、`wallMsgRow()`；`laptop()` 的标签角标只算 feed。
- `style-chrome.css`：`.wall-main`、`.wall-notice`、收件箱一整块。**类名全部 `wall-` 前缀**，因为 `.mail-note` 撞了游戏内手机邮件面板。`.post .wall-shot` 放大到 340（相册页仍是 148）。
- `web-i18n.js`：`wallNotice`、`wallOnlyUs`。
- `yue-zh.js`：新回复句与选项的普通话轨；删掉 5 条随改版变成孤儿的旧条目。
- `levels.js`：必做提示从「墙簿上有新回复，你还没回」改成「墙簿上有人等你回一句」——回复点现在可能在收件箱里。
- `图/游戏/README.md`：6 张新图逐张写清 + 一段「墙簿首页生活照的尺子」。

## 踩过的坑

- **`.mail-note` 撞车**：那条「只有你们两个睇得到」渲染成黑条（来自游戏内手机邮件面板）。整批类名改 `wall-` 前缀才干净。
- **CSS 与 JS 类名对不上**：第一轮批量替换把 `.msg-who-name` 变成 `.wall-msg-name`，JS 产出的是 `wall-msg-who-name` → 联系人行高 106px。改完类名要回 `grep` 一遍两边。
- **`goWeb("wall")` 只改 `S.screen` 不渲染**，探针必须走 `browseFromScene("wall")`。
- **触屏规则写在墙簿样式之前会被后面的 `.wall-draft-drop { padding: 0 }` 盖掉**：`.wall-draft-drop` 只有两个字，宽一直停在 22。把这整块 `@media (pointer: coarse)` 挪到 `.wall-draft-*` 定义之后才生效（34×32）。
- **mute 的条目也挂着「回覆」**（点了只出一句「你打了几个字，又删掉」），探针点第一个会误判成「草稿打不开」。要挑真正有 `answer` 的那条。

## 没做的

- 首页右栏还是旧的时间线／友邻那块，和新的帖子流有点重叠。这次没动。
- 通知条只有一条（廿八屋已租）。再加通知就往 `WALL_NOTICE` 里加，别再塞回收件箱。
- 收件箱的人名列还没做「最后一句是我说的」这种小标，暂时靠气泡左右分。

## 2026-10-30｜收件箱与倾偈并成一处：一页两栏，不是桌上再放一个窗

用户：「墙簿的收件箱和倾偈有点功能重复，是否可以两者合并？倾偈的界面风格我更喜欢，可否修改融合后做成新版收件箱？
『只有你们两个看得到。』这又是穿帮的设计，真实网页并不会带这个」，追问后选「合并到收件箱」。

### 判断

同一个人说的话只该在一处。表姐的实时私信（原倾偈窗口）和业主周的站内留言（原收件箱）
本来就是「这个人的消息」，分两个壳只是因为当初写在不同文件里。合并后：**收件箱就是倾偈那一页**，
左栏一个人一处，右栏是跟这个人的全部来往；`drawChat()` 与 `.chat*`／`.bubble*`／`im-desk` 整套删除。

### 画法（这是这一轮反复改的地方）

- **不能看着像「大界面套小界面」**：第一版是「窗口标题条＋×＋工具条＋状态条」，外面还套浅底与外框，
  四层框。现在只有一页两栏：左栏搜索＋人名，右栏对方一行＋对话＋发送，中间一条竖线；
  关掉靠站内那条「« 返回 墙簿」，跟这一站别的内页一样。
- **样式抄墙簿的 `.post`**：1px 细线、白底、无阴影、无圆角。不要弹窗那套。
- **类名不能借用 `.mail-*`**：那个前缀已经被「廿八屋站内留言」（`.mail-meta`／`.mail-body`）
  和手机邮件 iOS 7（`.mail-status`／`.mail-lock`）占着，借用会静默改坏那两处。一律 `inbox-*`／`ix-*`。
- **头像不要取名字首字**：灰底人形剪影（`::before` 头＋`::after` 肩）；表姐仍是照片。
- **不要解释性语言**：删掉「1 条，不分人也不分日子」「全部记录」「只有你们两个看得到。」——
  真实网页不会替玩家解释自己的版式。
- **搜索框常驻左栏顶上**：有字就是在翻旧记录（不分人不分日子），清掉就回这一栏；
  原来那个「查找记录」按钮点开才冒一条工具条，二〇一四年的网页上没有对应的东西。

### 触屏

搜索框 32 高、发送／回应／收起 ≥32×32；720 断点左栏改横条滚（`.inbox-people`），
选中态从左边一道竖线改成脚下一道（竖线在横条里看着像「左边界」）。
