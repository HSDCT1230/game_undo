## 起因

三条意见（附三张截图）：

1. 不同章节诊室的图中房间布局不一样，要整体统一，可以白天或黑夜，但格局要一致；

## 一、旁白为什么五处各一套

截图里那句「前台的姑娘喊道：阿文先生好了。章小姐，请进。」是**粗体、字距偏紧**，而同一段
对话里别的旁白是细的。第一反应是字号，量了才知道不是：

```
                 旧            截图那一句
场景旁白    18px / .1em    18px / .1em / 700  ← 字重不同
```

那 `700` 是 `awen-line` 干的：`talk.js` 里旧函数 `awenVisible(prompt)` 判「这句文本含『阿文』
且地点是候诊／澄心」，命中就同时做两件事——换背景图、给文本加 `.awen-line { font-weight: 700 }`。
**一条规则改了两样东西**，其中一样（换图）才是它真正想做的，加粗是顺带的。

把这条去掉之后，接着量字号，发现真正的问题在别处：旁白有**五条互不相干的渲染通道**，
各写一套：

| 通道 | 选择器 | 旧值 |
| --- | --- | --- |
| 场景旁白／选项提示 | `.talk.face .talk-text.stage-dir` | 18px / .1em / 1.95 |
| 章末字幕 | `.caption-text` + `.caption-line` | `--cap-lead = say-face*1.11` / .12em |
| 章节开场心声 | `.opening-lines` | 18px / .14em / 2 |
| 电话／短讯旁白 | `.talk.phone .talk-text.stage-dir` | 18px / .08em |
| 地点注 | `.room.scene-fit > .room-note` | **13px** / .06em |

同一句「走廊。四张椅，一块空白的牌子。」放在地点注里是 13px，放进场景旁白是 18px，
换到章末字幕又宽了字距——不是「不统一」，是根本没打算统一过。

## 二、改成一套：`--narr-*` 四格

`style-base.css` 加四格，五处一律取它：

```css
--narr-face: var(--brand-face);
--narr-size: var(--say-face);   /* 18px */
--narr-track: 0.1em;
--narr-lh: 1.95;
```

### 坑一：`0.1em` 写在容器上会被换算成绝对值再继承下去

字幕最先「改完了」，量出来却是 **1.2px**，不是 1.8px。

`em` 按元素**自己的**字号换算。`.caption-text` 没设 `font-size`（继承 body 的 12px），
`letter-spacing: 0.1em` 在那儿算成 `1.2px`，之后 `.caption-line`（18px）继承的是这个
**绝对值**，于是 18px 的正文只有 0.067em——比别处紧三分之一，而且肉眼看不出，只会觉得
「字幕的行读起来急一点」。

判据：盯着容器看不见，得量子元素。修法是把 `letter-spacing` 写到真正设了 `font-size` 的
那一层（`.caption-line`），并在注释里留一句「em 按自身字号算」。

### 坑二：写死 `em` 的单个变体

`.opening-line.goal`（开场最后那行「这一关要做的事」）单独写了 `letter-spacing: 0.16em`，
18px 上合 2.88px，比上面几行心声宽六成。改成 token。

### 三、`awen-line` 与那张假的候诊室

`00-通用/候诊-阿文.jpg` 是另一个房间：暖米墙、布椅、墙上「請保持安靜」牌子。
而候诊本身是冷灰墙、深灰布椅、木框茶几、左窗夜景。于是同一段对话里，
**逐句提不提阿文，背景就在两间房之间跳**。

- 字重：删 `.talk.face .talk-text.stage-dir.awen-line`。现在只有角色台词加粗，旁白一律 300；
- 图注：`图/游戏/README.md` 补「候诊那张是定装基准，别再造第二张」。

## 四、诊室外面那几分钟

`CLINIC_WAIT` 把第二／三／四次拆成候诊、走廊、前台三页，各三个看点，「入去」才进诊室。

**顶栏跟着走**：`syncPlace()` 对 `mode === "clinic"` 一律报「诊室」，而门外那几分钟
也是 `clinic`。结果是顶栏写诊室、图上却是走廊——这一条很可能就是「不同章节房间不一样」
的来源之一。加 `S.clinicWait`（`drawClinicWait` 置 true、`drawClinic` 置 false）后，
门外报「候诊」、进门报「诊室」。

### 洗手间那格重写

旧：副行「水开到底，台面是干的。」，弹窗「……不是洗手的那种开法，他在里面」。
问题不在线索本身（水这条线是主线），在于**腔口**：那是另一部戏的写法，
而且替玩家把「他在里面」说掉了。

新：

| 位置 | 文案 |
| --- | --- |
| 标题 | 洗手间的门 |
| 副行 | 水开到底，台面是干的。 |
| 弹窗 | 门关着。水声从门缝底下出来，开到底。／洗手台是干的，擦手纸也是干的。／你伸手把龙头关上。水声一停，走廊比刚才更静。 |
| 簿子 | 洗手间的水开到底。洗手台和擦手纸都是干的。他没洗手。 |

两处用意：① 物证只写看得见的（水开着、台面干、纸干），「他在里面」交给玩家推；
② 末句让她**真的把水关掉**——水声一停、走廊更静，接上她自己那句
「听到水声反而瞓到。声一停，我先惊。」（第 624 行）。同一个动作两处各有各的意思：
在诊所是替别人收拾，在家里是不敢让它停。

## 五、三张场景图到底是不是同一个房间

先别急着重画，量了再说。

| 图 | md5 前 12 位 | 结论 |
| --- | --- | --- |
| 6／8／10／12／14 的 `场景-候诊.jpg` | `11f997151169` | 五关**完全同一张** |
| 6／8／10／12 的 `场景-诊室.jpg` | `26a63ff0517f` | 四关同一张 |
| 14 的 `场景-诊室.jpg` | `52c6589ad2aa` | mean diff 3.15、仅 0.8% 像素 >30 |

那 0.8% 集中在办公桌右侧：**14 关桌上没有那本记事本**——这一关叫「拿笔记」，她拿走了。
是剧情，不是画错。

所以「布局不一样」不是章节之间的问题，是「阿文版候诊」那一张冒充了候诊室。
走廊／前台的墙面偏暖（`(1.027, 0.999, 0.974)` / `(1.01, 1.008, 0.982)`），
按候诊的 `(0.952, 1.001, 1.047)` 校色度，走廊强度 1.0、前台 0.6（近景全量会发灰）。

## 七、特意没做的

- **港繁的「着」不改「著」**。香港报刊一律用「着」（關着／睡着／隔着），
  改了反而离港式书面更远；且全站几十处，收益低、动面大。
- **候诊那张的黄昏窗、走廊的白天窗不改**。天色不一，但用户已明确「可以是白天或黑夜」，
  而格局（家具、门窗、空间关系）是一致的。真要统一得重画一张，等有别的理由再一起做。
- **诊室布局不重画**。06/08/10/12 与 14 的差异是「笔记本被拿走」，属于剧情。
