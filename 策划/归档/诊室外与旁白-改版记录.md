## 起因

三条意见（附三张截图）：

## 一、旁白为什么五处各一套

截图里那句「前台的姑娘喊道：阿文先生好了。章小姐，请进。」是**粗体、字距偏紧**，而同一段
对话里别的旁白是细的。第一反应是字号，量了才知道不是：

```
                 旧            截图那一句
场景旁白    18px / .1em    18px / .1em / 700  ← 字重不同
```

那 `700` 是 `awen-line` 干的：`talk.js` 里旧函数 `awenVisible(prompt)` 判「这句文本含『阿文』
且地点是候诊／澄心」，命中就同时做两件事——换背景图、给文本加 `.awen-line { font-weight: 700 }`。
**一条规则改了两样东西**，其中一样（换图）才是它真正想做的，加粗是顺带的。

把这条去掉之后，接着量字号，发现真正的问题在别处：旁白有**五条互不相干的渲染通道**，
各写一套：

| 通道 | 选择器 | 旧值 |
| --- | --- | --- |
| 场景旁白／选项提示 | `.talk.face .talk-text.stage-dir` | 18px / .1em / 1.95 |
| 章末字幕 | `.caption-text` + `.caption-line` | `--cap-lead = say-face*1.11` / .12em |
| 章节开场心声 | `.opening-lines` | 18px / .14em / 2 |
| 电话／短讯旁白 | `.talk.phone .talk-text.stage-dir` | 18px / .08em |
| 地点注 | `.room.scene-fit > .room-note` | **13px** / .06em |

同一句「走廊。四张椅，一块空白的牌子。」放在地点注里是 13px，放进场景旁白是 18px，
换到章末字幕又宽了字距——不是「不统一」，是根本没打算统一过。

## 二、改成一套：`--narr-*` 四格

`style-base.css` 加四格，五处一律取它：

```css
--narr-face: var(--brand-face);
--narr-size: var(--say-face);   /* 18px */
--narr-track: 0.1em;
--narr-lh: 1.95;
```

### 坑一：`0.1em` 写在容器上会被换算成绝对值再继承下去

字幕最先「改完了」，量出来却是 **1.2px**，不是 1.8px。

`em` 按元素**自己的**字号换算。`.caption-text` 没设 `font-size`（继承 body 的 12px），
`letter-spacing: 0.1em` 在那儿算成 `1.2px`，之后 `.caption-line`（18px）继承的是这个
**绝对值**，于是 18px 的正文只有 0.067em——比别处紧三分之一，而且肉眼看不出，只会觉得
「字幕的行读起来急一点」。

判据：盯着容器看不见，得量子元素。修法是把 `letter-spacing` 写到真正设了 `font-size` 的
那一层（`.caption-line`），并在注释里留一句「em 按自身字号算」。

### 坑二：写死 `em` 的单个变体

`.opening-line.goal`（开场最后那行「这一关要做的事」）单独写了 `letter-spacing: 0.16em`，
18px 上合 2.88px，比上面几行心声宽六成。改成 token。

### 洗手间那格重写

旧：副行「水开到底，台面是干的。」，弹窗「……不是洗手的那种开法，他在里面」。
问题不在线索本身（水这条线是主线），在于**腔口**：那是另一部戏的写法，
而且替玩家把「他在里面」说掉了。

新：

| 位置 | 文案 |
| --- | --- |
| 标题 | 洗手间的门 |
| 副行 | 水开到底，台面是干的。 |
| 弹窗 | 门关着。水声从门缝底下出来，开到底。／洗手台是干的，擦手纸也是干的。／你伸手把龙头关上。水声一停，走廊比刚才更静。 |
| 簿子 | 洗手间的水开到底。洗手台和擦手纸都是干的。他没洗手。 |

两处用意：① 物证只写看得见的（水开着、台面干、纸干），「他在里面」交给玩家推；
② 末句让她**真的把水关掉**——水声一停、走廊更静，接上她自己那句
「听到水声反而瞓到。声一停，我先惊。」（第 624 行）。同一个动作两处各有各的意思：
在诊所是替别人收拾，在家里是不敢让它停。

是剧情，不是画错。

所以「布局不一样」不是章节之间的问题，是「阿文版候诊」那一张冒充了候诊室。
前台墙面偏暖（`(1.01, 1.008, 0.982)`），按候诊的 `(0.952, 1.001, 1.047)` 校色度，强度 0.6
（近景全量会发灰）。

### 走廊那张：调色不够，得重画

第一轮只把走廊的墙面色度校到候诊，截图一看仍不对——**椅子不是同一款**：
候诊是深灰布面、**宽平木扶手**、方锥木腿；走廊是米色布面、**细圆木扶手**、细木腿。
而且走廊墙是暖米、候诊墙是冷灰，窗外一个白天一个黄昏。

这两个空间属于同一间诊所（第 14 关里玩家会连着看到候诊的对话底图和走廊的房间页），
只是调色拉不平，于是以**候诊为母图**重画走廊：椅子换同款、墙转冷浅灰、地板冷灰塑胶、
左窗改白天阴天、走廊两扇门加尽头一扇照旧、空白牌子照旧。

重画后连带两格缩略图又不统一了——`示意-洗手间的门.jpg` 与 `示意-走廊最里面.jpg`
还是暖米墙（后者左下角还露着旧款米色椅的扶手）。这两张按新底图的墙面色度
`(0.99, 1.00, 1.015)` 校过（gains `[0.977, 0.994, 1.036]` / `[0.957, 0.986, 1.068]`），
只改色度、亮度拉回原样。

判据：底图与三格缩略图并排看，墙面、门色、地板三样要能读成同一条走廊。
颜色上仍留一点差异——候诊那扇窗朝西（黄昏紫天），走廊尽头朝北（阴天灰白），
真实建筑里本来就同一天两个天色，不必强求一致。

## 2026-10-30｜初诊走出诊室的那个男人：先说明他不是罗医生

用户附截图：「初诊见到林伟森这个描述容易让人迷惑，因为是第一次见面，大部分玩家会以为这是罗医生。
后半段建议改成『有个没戴铭牌的男人走出来，高个，干瘦，苍白。出门时他笑了一下，你却没看清脸，
想仔细看，他很快转身下楼消失了』。」

### 问题出在哪儿

原来三句：

> 你早到十分钟。诊室门开了，有人走出来。身子很瘦，窄脸看不清，只看见细框眼镜上的光。脸色白，衬衫扣到最上面一颗。
> 杂志倒拿着。他对你笑了笑，很客气，笑停在脸上。胸前没有名牌。
> 门还开着。你发现自己已经先笑了一下，笑得很浅。诊室里的人站了起来。

- **「有人走出来」没说是谁。** 她还没见过罗启明，画面里第一个男人就被填成「医生」——这是读者唯一能走的路。
  后面「诊室里的人站了起来」又把二号男人塞进来，两次「有人」撞在一起，第一印象就固定错了。
- **「胸前没有名牌」排在第三句、还是肯定句**。玩家读到的是「哦，这家诊所的人不戴名牌」，
  而不是「他不属于这儿」。否定要放在**最前面**，而且要给一条行为证据：走出来之后**往楼下走**。
- **五行都是形容词**（瘦、白、客气、看不清），没有一件能复述的东西——后文靠什么认出他？

### 改后

> 你早到十分钟。诊室门开了，有个没戴铭牌的男人走出来。高个，干瘦，脸色白，衬衫扣到最上面一颗。
> 杂志倒着拿。出门时他笑了一下，很客气。你却没看清脸——想仔细看，他已经转身下楼，脚步声很快没了。
> 门还开着。诊室里的人站了起来。你发现自己已经先笑了一下，笑得很浅。

- 「没戴铭牌」提到最前，紧跟着「走出来」，等于一句「他不是这儿的人」。
- 「转身下楼，脚步声很快没了」是**行为上的排除**：在这儿上班的人不会从诊室出来就下楼。
- 「你却没看清脸」明说记不住——第二、三次她才把人对上（原有那句「还是很瘦，细框眼镜」照旧，
  这次读起来正好是「看清了一点」）。
- 「杂志倒着拿」留着：第二次他把倒着的杂志递到她手里，靠的就是这件东西。
- `linWait` 那条笔记一起改（「上一个病人。没戴铭牌。高个，干瘦，脸色白。杂志倒着拿。没看清脸。」），
  `levels.js` 里「诊室（候诊已过）」那条快捷入口的预置笔记同步——两处若不同步，
  从入口直接进第 12 场的人会抄到一条对不上正文的笔记。
