# 番外

只给读者看的小说。正片不做进游戏，不进对白、界面、Flag。

与正片冲突时，以 [人物志](../人物/05-人物志.md) 与各章剧本为准。番外可以把正片里只准漏半秒的东西写成场面，也可以为可读性另起无名配角、房间、器物和私密日程——那些东西不到游戏里去。

正文补什么、不补什么：

- **成人向不进正文。** 钟点房、酒店、浴室、录像、身体过程、道具场面，只留在番外。正片给章的那封信不写他跟谁睡过，也不写「当药」。信上是二〇〇四年十一月维港大学女学生坠楼的旧闻，名字涂掉，加一张学生时代偷拍：年轻的罗和一个望住他的长发女生。下一个就是你。女人死了是真，他逼她跳是假。男人那张相留在林的抽屉，四章才见：睡过是真，旧情人是假。不准写房间和身体。
- **性格、因果、口语可以反向补进正文。** 番外写清楚了、正文缺的，补回去。例如：三秒尺子中学已有；面试「我想听人讲完」；毁掉练习簿上的电话和值班室门口虚焦相；教科书都会呃人；旧号空号五年；共享位置「万一」；林不杀陈，因为杀了阿明只看见血。

人名仍用正片口径：陈家豪，不写错字。小鱼家里只用小鱼父亲、小鱼母亲、小鱼哥哥。番外里多出来的人，能不取名就不取名。

按中篇写。畸形的爱恋写足，不收成大纲。前四篇不合并：罗、陈、林、小鱼、许生已经各有自己的日子。后面的篇把原先只当功能的人写成完整的人。杰仔不开口，番外也不让他提前说话。心理上的词第一次出现时用生活说法拆开：封条＝自己定的规矩（不提那个名字、看人不超过三秒）；容器＝把人当用来倒心事的盒子；正文不再用「当药」。解离在正片里是：上门记得，白房里对不上那个女人。对照见 [策划纲要](../设定/00-策划纲要.md)。
