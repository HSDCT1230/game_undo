# 策划

对稿以本目录为准。可玩工程在 [游戏/](../游戏/README.md)。

| 文件夹 | 问什么 | 放什么 |
| --- | --- | --- |
| [设定](设定/README.md) | 规则、何时、机制为什么成立 | [纲要](设定/00-策划纲要.md)、[因果与名词](设定/06-因果与名词.md)、[时间线与因果](设定/07-时间线与因果.md) |
| [人物](人物/README.md) | 这个人是谁、知道什么 | 人物志、关系图；人设图见 [图/人物](../图/人物/) |
| [剧本](剧本/README.md) | 这一场看见什么、选了怎样；**改对话从 [改对话](剧本/改对话.md) 进**；通读见 [故事](剧本/00-故事.md) | [改对话](剧本/改对话.md)；[故事](剧本/00-故事.md)；第一～四章分场；[对话分支](剧本/08-对话分支.md) |
| [番外](番外/README.md) | 只给读者看的小说 | 不做进游戏。成人向只留番外，不补进正文；性格、因果、口语可以反向补进正文。与正片冲突时以人物志与各章剧本为准 |

图库：[图/](../图/README.md)。游戏图总表：[图/游戏/README.md](../图/游戏/README.md)。

## 谁做主

每个话题只准一份做主。别处只留一句加链接。

| 话题 | 真相源 | 别处只留 |
| --- | --- | --- |
| 玩法规则、物件、体例、仍砍、人名怎么叫 | [策划纲要](设定/00-策划纲要.md) | — |
| 信息权限（谁知道／不知道） | [人物志](人物/05-人物志.md) 各人节 | 纲要只留「本章结束仍不准」4 行 |
| 四章停在哪里 | 各章剧本文首 | 纲要 4 行索引 |
| 三层鬼是什么 | [人物关系图](人物/人物关系图.md) §5 | 纲要一句；时间线只留「哪章可钉」 |
| 表面／隐藏／阴谋关系 | [人物关系图](人物/人物关系图.md) | 人物志开头三段摘要 |
| 人设、这句话为什么会说 | [人物志](人物/05-人物志.md) | — |
| 周林勒索、政策名词 | [因果与名词](设定/06-因果与名词.md) | 纲要「两处房产」只留事实 |
| 总年表、八月日表、三线、必须成立的因果 | [时间线与因果](设定/07-时间线与因果.md) | 关系图「故事六步」；纲要一行主轴 |
| 选项类型、Flag、汇合 | [对话分支](剧本/08-对话分支.md) | 各章剧本只写选项文案和当场后果 |
| 读感、主路节奏、同一夜怎么叠 | [故事](剧本/00-故事.md) | 各章仍管台词和界面 |
| 一章分几关、每关怎么过、后半段星期六弧 | [01 关卡](剧本/01-第一章-关卡.md) | 各章场次头只标第几关；纲要一句口诀 |
| 读者向小说（不做进游戏） | [番外](番外/README.md) | 成人向不进正文；性格、因果、口语可反向补。正片对白、界面、Flag 仍不引用番外篇名 |
| 台词、界面、本场目的 | 各章剧本；改对话工作流见 [改对话](剧本/改对话.md) | 游戏里再对 `story.js` |
