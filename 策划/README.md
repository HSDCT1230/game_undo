## 谁做主

每个话题只准一份做主。别处只留一句加链接。

| 话题 | 真相源 | 别处只留 |
| --- | --- | --- |
| 玩法规则、物件、体例、仍砍、人名怎么叫 | [策划纲要](设定/00-策划纲要.md) | — |
| 信息权限（谁知道／不知道） | [人物志](人物/05-人物志.md) 各人节 | 纲要只留「本章结束仍不准」4 行 |
| 四章停在哪里 | 各章剧本文首 | 纲要 4 行索引 |
| 三层鬼是什么 | [人物关系图](人物/人物关系图.md) §5 | 纲要一句；时间线只留「哪章可钉」 |
| 表面／隐藏／阴谋关系 | [人物关系图](人物/人物关系图.md) | 人物志开头三段摘要 |
| 人设、这句话为什么会说 | [人物志](人物/05-人物志.md) | — |
| 周林勒索、政策名词 | [因果与名词](设定/06-因果与名词.md) | 纲要「两处房产」只留事实 |
| 总年表、八月日表、三线、必须成立的因果 | [时间线与因果](设定/07-时间线与因果.md) | 关系图「故事六步」；纲要一行主轴 |
| 选项类型、Flag、汇合 | [对话分支](剧本/08-对话分支.md) | 各章剧本只写选项文案和当场后果 |
