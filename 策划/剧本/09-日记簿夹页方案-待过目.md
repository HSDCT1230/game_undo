# 日记簿夹页／物件方案（已实装）

**定案（2026-10-11）**：六项全做；可删的对白一起删／缩；第 2 项月历 9/6 那格写「医生」；第 4 项划掉的那一行保留。五张新图在 `图/游戏/README.md` 标了「（待补）」，图到之前游戏里是灰块，全检只报 WARN。文末「想请你决定的」四问已答，留作记录。

目的：有几处信息现在是靠人物「讲出来」或旁白「交代出来」的。改成玩家自己翻到、看到，对白就能短一点，玩家也会觉得是自己发现的。

原则：

- 只挪「事实」（日期、名字、谁写了什么），不挪「态度」。人物怎么说、怎么躲，仍然留在对白里。
- 每一项都要能**不看也能通关**，看了会多懂一层。
- 不新造界面。全部用游戏里已有的三种做法（见下面「通用做法」）。
- 要补的图都列在每项末尾，进 `图/游戏/待补图.md`。图没到之前，游戏会显示「待补图」灰块，不影响玩。

## 通用做法（每一项都是这三步）

1. **登记一张夹页**：在 `游戏/assets/diary.js` 的 `ITEMS` 里加一条，例如：

   ```js
   "obj-keytag": { kind: "物件", title: "钥匙牌", time: "2014年8月1日", body: "大门　铁闸　天台……", img: pic(2, "证据-钥匙牌"), key: "水喉坏咗拍门" },
   ```

   `kind` 决定它在日记簿里归哪一类（现有：纸、照片、录音、记下、信封、电话、邮件；这次新加「物件」）。`key` 是日记簿里高亮的那半句。

2. **放一个能点的东西**：在那一关的场景（`HUBS.xxx.places[].spots`）里加一张卡：

   ```js
   { title: "钥匙圈", sub: "绑着一块硬纸牌。", img: pic(2, "示意-钥匙圈"),
     seen: () => ev("obj-keytag"),
     go: () => (ev("obj-keytag") ? showClueModal(item("obj-keytag"), { canFile: false }) : keepThen(item("obj-keytag"), backToHub)) },
   ```

   第一次点：弹出夹页，玩家按「夹进日记簿」收下。再点：只看不收。
   如果那一段是对话而不是场景，就在对话里加一个选择（「看一眼」／「不看」），选「看一眼」才 `keepThen(item(...))`。

3. **删或缩对白**（你决定要不要删，见文末第 2 问）。

验收：`node tools/全检.mjs` 0 个错误；无头浏览器把「看」和「不看」两条路各走一遍到结局。

## 1. 钥匙牌（第 2 关 · 交按金）

**限制**：已经定了这次租房是「口头讲，冇印花」，所以**不能**出现正式收据或租约，也不写租金数目（日记簿里租金只记「每星期三千几」）。

**要注意**：`afterTour()` 里现在有一句「他收现金，手写一张收条，钱数了两遍」。钥匙牌和这张收条是两样东西。建议收条这句保留，但收条本身不进日记簿（有金额，会和「三千几」打架）。

**现在**：周在 `payDeposit()` 里口头讲规矩；入住时天台钥匙靠 `story-early.js` 里 `hot("天台钥匙")` 的弹窗交代（「周先生说过：晾衫用」）。

**改成**：交按金后周递过来一串钥匙，钥匙圈上绑着一块他手写的硬纸牌：

> 大门　铁闸　天台（挂门内小钩）
> 水喉坏咗拍门。唔使自己整。
> 天台晾衫用。

**怎么做**：

- `ITEMS` 加 `obj-keytag`（kind「物件」）。
- 第 2 关 `afterTour()` 两个选项的结尾都是 `{ goto: () => finishLevel(2) }`，改成 `{ goto: () => keepThen(item("obj-keytag"), () => finishLevel(2)) }`：她接过钥匙，夹页弹出来，收下后才过关。
- 第 3 关入住场景里 `hot("天台钥匙")` 的弹窗缩成一句「第三把挂在门内小钩上。纸牌上写着：天台晾衫用。」

**后面用到**：08-03 修水龙头（「唔使自己整」）、第 15 关天台钥匙的选择、天台夜。
**图**：`02-看房-8月1日/证据-钥匙牌.png`

## 2. 周的月历（第 11 关 · 楼梯口）

**现在**：两周日历里 08-10 那天的对话只有一句旁白「他点点头，在门边的月历上写了一笔」（`story-early.js` 约 421 行）。

> 8/1　后座入伙
> 8/3　换胶圈
> 8/10　租。问电话——冇。
> 8/16　~~入~~（涂掉）
> 8/23　六　出
> 8/30　六　出

**怎么做**：

- `ITEMS` 加 `obj-zhoucal`（kind「物件」）。
- `story-clinic.js` 第 11 关场景的「楼梯口」（`id: "stair"`）现在只有一张「周生」卡。加第二张卡「前座门边的月历」，`show: () => ev("note-zhoutue")`（周说完话、回了前座才出现）。

**作用**：玩家自己发现周在记她的作息，而且记了「星期六出门」。`note-zhoutue`（「我没讲」）从「周说了一句」变成「我亲眼看到他写的」。

## 4. 阿明留下的一页现场笔记（第 13 关 · 他走之后）

**现在**：笔记整本在第 14 关被偷，玩家只听到「夹子里有本」「本子不见了」，从来没看过里面写什么。

**改成**：阿明在水龙头那里写完，把今晚那页撕下来，压在地上的玩具车下面——他答应过「听日执好笔记俾你」，这一页是先给她的。旁白不提。他走后，厅里多出一张卡「车底下」：

> 9/6　21:52　荣汇街后座
> 水喉：拧紧后约 3 秒再滴。人手可做到。
> 车：头朝储物室门。
> 走廊尽头——（这一行用力划掉）
> 不写「鬼」。

**怎么做**：

- `ITEMS` 加 `paper-ming`（kind「纸」）。
- `story-late.js` 的 `HUBS.visit` 里「厅」（`id: "hall"`）加一张卡「车底下」，`show: () => !!S.visit.left`（送他走之后才出现，和走廊的「耳朵贴储物室门」同一时间）。
- 这样第 14 关整本笔记被偷时，玩家手里已经有一页，被偷这件事更痛。

**作用**：玩家第一次看到他「没写鬼」的原件；划掉的那行和他在走廊看到长发女人对上，不用他自己解释。第 13 关新加的「『鬼』字我唔写」就有了实物回应。
**可删的对白**：`leadTap()` 最后那句旁白「他在夹子里的本子上写了一句。没有写鬼。」

## 5. 诊室抽屉缝（第 10 关 · 第三次诊所）

**现在**：`clinic3()` 一开场就用旁白讲「抽屉缝开着一点……一封折好的信，封口朝里，回形针卡住」，然后自动记下 `refEdge`。

**要注意**：第三次诊所没有「诊室场景」（第 1、4 次才有可以点的执照／抽屉／电脑），一进去就是对话。所以这一项只能做成对话里的选择。另外，`clinicHots()` 里给第三次准备的那段抽屉文字（`visit >= 3` 分支）现在根本走不到，是死代码。

**改成**：旁白只说「抽屉缝开着一点。」然后给一个选择：

- 「看一眼」→ 只看到信封一角：「……转介」（下面被回形针压住）。记下 `refEdge`，夹页进日记簿。
- 「不看」→ 他把抽屉推上，什么也不记。

**怎么做**：

- `ITEMS` 加 `obj-referral`（kind「信封」）。
- `clinic3()` 开头那两句旁白和 `{ note: ["refEdge", ...] }` 换成上面的选择。`refEdge` 后面没有任何地方读，删掉不影响别的剧情。
- 顺手删掉 `clinicHots()` 里走不到的 `visit >= 3` 抽屉分支。

**作用**：转介这条线从「被告知」变成「瞄到的」，跟后面「上一个号又拖过时」更像玩家自己的怀疑。
