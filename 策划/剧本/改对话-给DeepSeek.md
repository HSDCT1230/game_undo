# 改对话 · 给 DeepSeek（或其它模型）的提示

复制下面模板，把「附件」换成：导出表片段、`story.js` 某个 `function …` 整段、或剧本一场。  
改完后你自己贴回 `story.js`（或剧本），再按 [口吻与全检](改对话-口吻与全检.md) **全量**过一遍——可要求模型「列出它改过的每一行」方便你核对，但仍须你或助手对该范围全量检验。

工作约定总入口：[改对话.md](改对话.md)。

```
任务：只改「普通话」列（或 JSON/代码里的 zh 字段），让它像人说的普通话，贴人设与剧情上下文；可增删润色，不要逐字硬译粤语。不要改粤语列，不要改旁白，不要改选项 Flag 名。
```

## 模板 B · 加轮次（粤+普都写）

```

约束：
- 章细碎，罗短句白话，陈碎半句，美娟碎嘴关心。

- 插在我标明的两句之间；不要改 Flag/goto/choices。
- 每条都要粤+zh；旁白用 line("", "……") 且不要 zh。
- 全量给出要插入的全部新行，不要只给样例。
- 地名用大角咀。

锚点（插在这句后面）：
（粘贴上一句 line）

后面紧接的原句是：
（粘贴下一句 line）
```

```
不要抽查：输入有几条就审几条。不要改粤语，除非粤语明显写成普通话且你单独标注「粤语也建议改」。
```

## 贴回游戏后你要做的

1. 在 `游戏/assets/story.js` 对应函数替换／插入。  
2. 保存为 UTF-8。  
3. `游戏/index.html` 里 `story.js?v=` 加一。  
4. 浏览器 `游戏/index.html?level=N` 听主路。  
5. 用 [口吻与全检](改对话-口吻与全检.md) 对该函数／关 **全量**打勾。  

导出命令：`node 策划/剧本/导出对白.mjs`（在仓库根目录）。
