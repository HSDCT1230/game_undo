检查方式：**全量**（非抽查）。脚本先把全部 1076 条可显示文本对抽出来（角色话 632 / 旁白 262 / `T()` 73 / 网页词条 97 / 字段对 10），再逐字过 `s2hk.js` 的转换表做机械判定，可疑项逐条人工看上下文。
工具：`tools/_bin/qc-lang-text.cjs`、`qc-lang-chars.cjs`、`qc-lang-probe.cjs`（只读，已落盘 `qc-lang-text.json` / `qc-lang-chars.json`）。

## 2. A 类 · 简繁转换的系统性错误

### 2.1 根因（一句话）

`游戏/assets/s2hk.js` 的 `toHkTrad()` 是**逐字查表**，没有词组表保护；而这张表由 `tools/_bin/build-s2hk.ps1` 用 OpenCC 的 `STCharacters` 生成，脚本第 21 行只取**候选列表的第一个字**：

```powershell
$map[$parts[0]] = $parts[1].Substring(0, 1)
```

OpenCC 原表里这些是多候选：

```
只	只 隻 祇          → 取「只」= 与源字相同 → 第 44 行 continue 整条丢弃
系	系 係 繫          → 取「系」→ 丢弃
松	松 鬆             → 取「松」→ 丢弃
舍	舍 捨             → 取「舍」→ 丢弃
折	折 摺             → 取「折」→ 丢弃
面	面 麪             → 取「面」→ 丢弃
干	幹 乾 干 榦        → 取「幹」（错，该处语境全是「乾」）
发	發 髮             → 取「發」（「頭髮」错）
郁	鬱 郁             → 取「鬱」（粤语「动」错）
冲	衝 沖             → 取「衝」（「沖涼」错）
复	復 複 覆          → 取「復」（「回覆」错）
搵	搵                → 后被 HKVariants 段 `'搵':'揾'` 覆盖
```

所以 **前 6 个字（系/只/松/舍/折/面）根本没进表 → 粤语模式下原样显示简体**；后 5 个字（干/发/郁/冲/复）**进了表但取错了候选 → 转出错字**。
修法方向（供参考，未动）：改成先查词组表、再逐字回落；并把 `系→係`、`只→隻`、`松→鬆` 这类按上下文判定。

## 3. B 类 · 粤语模式下仍是简体的界面（未做语言化）

`toHkTrad` 只在 `core.js`(T/Ts/Tblock)、`talk.js`、`web-ui.js`、`story-late.js:1132` 四处被调用。
下面这些界面**完全没有语言处理**，所以 `粤语` 模式下照样显示简体，与「粤语＝香港繁体」的预期不符：

| 界面 | 位置 | 例子 |
| --- | --- | --- |
| 开场心声 | `levels.js` `OPENING_SAY`(832) + `LEVELS[1].goal` | 「五月分手了，短租、日租……」 |
| 关卡标题／「要做」／清单／提示／下一站 | `levels.js` `LEVELS[2..16]`（如 :23-31, :49-56） | 「把求助帖顶上去」「看清这间屋，跟周生谈妥。」 |
| 日记簿（含笔记正文、时间轴） | `diary.js` 全表；渲染在 `ui.js:181`（直接放 `n.text`） | 「钥匙圈上硬纸牌，周先生的字……」 |
| 线索卡／证物卡 | `levels.js` 清单 + `ui.js` | — |
| 图槽说明 `baseSheet(...)` | `story-*.js` 里大量调用 | 「一辆旧红色塑料敞篷玩具车……」 |
| 地图 | `map.js` | — |
| 图鉴 | `pics.js` | — |
| 存档卡 `resumeCaption()` | `levels.js` | — |

**要你确认的两选一**：这些是「系统 UI，理应恒为简体」，还是「也属于粤语模式该转繁体的正文」？
（`core.js:62` 的注释写的是「粤／普：对白与网站共用」，若照这条，B 类属于**设计如此**，只是文档没写清；但玩家在粤语模式看到「对白繁体＋日记简体」并存，观感上会像 bug。）

## 7. F 类 · 文档与实现不符（1 处）

**`游戏/README.md:76`**：

> 「粤＋普／粤语／普通话」：角色台词**显示双语**、只显示粤语，或只显示普通话（键 `undo-lang`）。**只影响 `talk.js` 的 `talkBody()`**，旁白、选项、短讯不变。
