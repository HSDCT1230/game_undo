## 1. 转繁层（`s2hk.js`）

生成表有 2727 条单字映射，但生成时只取 OpenCC 候选的**第一个字**，第一个字等于源字就整条丢弃——于是同时存在「该转没转」和「转错候选」两类系统性错误。这次在生成表**前面**加了一层手工修复（不改生成表本身，重建后仍可整体替换）：

| 层 | 规模 | 作用 |
| --- | --- | --- |
| `S2HK_WORDS` | **410 条** | 词组最长匹配，命中就整段输出。既是「保护」（`系列/只有/宿舍/公里/周先生/表姐/注意`），也是「纠错」（`头发→頭髮`、`回复→回覆`、`钟意→鍾意`、`面档→麵檔`） |
| `S2HK_FIX` | **37 条** | 单字覆盖：纠正错候选，并中和生成表里 5 条会把繁体改坏的条目（`說→説`、`戶→户`、`稅→税`、`溫→温`、`線→綫`） |
| `S2HK_MAP` | 2727 条 | 原生成表，兜底 |

具体处理：

| 原问题 | 原表现 | 现在 |
| --- | --- | --- |
| `系` 290 处 | 一直是「系」 | `唔係 / 都係 / 係咪 / 只係`；`系統/關係/聯繫/體系/系列/直系/係數` 按词保留 |
| `郁` 25 处 | `唔好鬱就得` | `唔好郁就得`（粤语「动」就是郁） |
| `干` 23 处 | `掛得很幹淨` | `乾淨/乾嘅/曬乾`；`干涉/若干/幹部` 分开处理 |
| `只` 29 处 | 量词不转 | `一隻手/另一隻`；`只有/只是/唔只/只係` 保留 |
| `松` 14 处 | `松了一口气` | `鬆了一口氣` |
| `发` 6 处 | `頭發` | `頭髮/長髮/髮尾`；`發布/沙發` 仍是「發」 |
| `搵` 4 处 | 被转 `揾` | **保留 `搵`**（香港常用写法） |
| `舍/折/复/面/冲` 27 处 | 混装 | `宿舍` vs `唔捨得`；`摺好`；`回覆/反覆`；`麵檔`；`沖涼` vs `衝出去` |
| `签` 9 处 | 被转 `籤` | `簽署/簽名`；`抽籤/書籤` 才是籤 |
| `伙` 6 处 | `入夥` | `入伙`；`夥伴/合夥` 才是夥 |
| `床` 3 处 | 被转 `牀` | `床單/床位`（港标用床） |
| `晒` 8 处 | 助词被转 `曬` | `聽晒/攬晒上身` 保留 `晒`；`曬痕/曬太陽` 转 |
| `钟` 28 处 | `十分鍾` | `分鐘/鐘錶`；只有`鍾意/姓鍾`用鍾 |
| `说` 23 处 | 日式 `説` | `說`（港标） |
| `户/税/温` 14 处 | 一直是简体 | `戶/稅/溫` |
| `志/注` 6 处 | `雜志` | `雜誌`；`註冊/備註`（`注意/關注` 保留） |

顺带补的：`赞→讚`（称赞）、`并→併`（鞋并上去）、`里→裏`（家里，但`公里/里程`保留）、`周→週`（周末，但`周先生/周租`保留）、`布→佈`（公布，但`布料`保留）、`才→纔/剛才`、`卷→捲`、`杆→桿`、`借→藉`、`向→嚮`、`回→迴`、`了→瞭`、`面→麵`、`卫→衛`。

## 2. 界面与关卡（原来永远简体）

`core.js` 新增 `H(s)`：粤语／粤＋普 → 港繁，普通话 → 原样。`el()` 在把字符串塞进 DOM 时统一走它。

- 于是 `diary.js`(356) / `pics.js`(209) / `map.js`(109) / `ui.js`(60) / `hub.js`(4) 这 **738 条**字面量，不用一条条改，粤语模式自动是港繁。
- `levels.js` 的 16 条 `goal` + 80 条 `text` + 48 条 `hint` + 38 条 `after`（**181 条**）同样生效。
- 幂等：已经是繁体的文本再走一次 `H()` 不变，所以 `T()` 的结果不会被二次改坏。

`H()` 与 `T()` 的分工写进了 `游戏/README.md`：`T()` 给有双语来源的文本，`H()` 给只有一种写法的文本。
