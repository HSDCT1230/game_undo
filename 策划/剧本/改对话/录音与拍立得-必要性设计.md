# 录音与拍立得：怎么让它们「后面真有用」

写于 10-28。**这一份只谈设计，代码一行没动。** 由你拍板，我再落。

起因是你问的那句：「这里的录音不点是不是也没有影响？」

我先去把它查实了。答案是——**基本没有影响**，而且比没影响更糟：有一处戏在她从来没录过音的情况下照样演。

---

## 1. 先说查实的账

### 录音：三处漏气，堵死了

| # | 位置 | 现状 | 后果 |
| --- | --- | --- | --- |
| 1 | `levels.js:120` | 必做「开录音」没有 `need: true` | 不开也能按「往下」，任务条上的勾只是装饰 |
| 2 | `story-early.js:1341` | `missedVoice = !!(n.recording && !n.fired.voice)` | **没开录音 → 这个条件是 false**，于是 `waitDawn()` 一声不响直接放行。反过来了：开了却睡过去的有人提醒，压根没开的没人管 |
| 3 | `diary.js:656` | `ensureCompareMaterials()` 见到 `S.tonight.storage` 就自动补发 `rec-axuan` | 第 9 关开对照纸时，簿子里凭空多出那卷录音 |

第三条最要命。她点一下储物室门底就算「碰过」，保险丝就把录音补进簿子——这个保险丝本身是对的（防旧档、防跳关卡死），问题在于它补得太早，把「当场有没有录」这件事彻底抹平了。

### 一处穿帮

`story-clinic.js:1145`，第 8 关二诊：

> 他戴上耳机听录音，听完才摘下来。
> 罗启明：「把声好稳。似留过言，唔似当场叫你。」

往前两行，她说「呢卷我日日听」。

**这两句是无条件的。** 玩家如果第 4 关整夜没按过录音键，她簿子里根本没有那卷东西——他照样听，照样评价。接着 `:1162` 他又说「呢个礼拜，有一晚唔好开录音」，那句医嘱本身就建立在「她有录音习惯」上。

所以录音不是「不够必要」，是**剧本已经假设它必要了，机制没跟上**。伏笔也早就写了：第 3 关那条必做「日历上，夜里那卷录音」，那卷「只有水」是玩家亲手开的。第 3 关教会她「录音＝证据」，第 4 关没有兑现。

### 拍立得：一半是真的，一半是空的

| 处 | 是否必要 | 说明 |
| --- | --- | --- |
| 第 5 关「给玩具车和水龙头各拍一张」 | **真必要** | `levels.js:141` 有 `need: true`，而且 `paper-16` 的正文直接引白边上的 14:30 |
| 第 6 关交证物（`note-dry / photo-sill / photo-print` 三选一） | 假必要 | `note-dry` 是 `keepMust`，一定有；照片那一支永远不是唯一解 |
| 第 4 关夜场两张（窗台、湿脚印） | 不必 | 湿脚印点开就 `markTonight("print")`；`photo-print` 由 `ensureCompareMaterials()` 无条件补 |
| 对照纸 `sill` 行 | 不必 | 右侧有 `photo-sill` 和 `tonight:sill` 两个口子，后者擦一下就开 |
| 相纸八张 | 无压力 | `POLAROID_IDS` 最多用掉 4 张 |

**拍立得的问题不是「没用」，是「用对了地方也不加分、用错了地方也不扣分」。**它在第 5 关已经是真证据了，玩家却不知道自己刚才做的那件事叫「取证」——因为没人当着她的面说过「相上面有时间」。

## 2. 判据

沿用 `11-13关决策设计.md` 那三条（专属台词／有人记住／下一关因此不同），换成证据的语言：

1. **有人点名要。** 不是 UI 说「这个以后有用」，是**在场的人开口问**。
2. **缺席换一条路，不是少一段字。** 缺证据要改的是**之后发生什么**，不是「你错过了一段」。
3. **不许自动补。** 正常流程里，缺席就是缺席；保险丝只在旧档和跳关里生效。

再加一条这个游戏自己的规矩（写在记忆里）：

4. **不写提示条。** `tip()` 一响，玩家就知道这是任务；而这个游戏的味道是她自己搞不清哪件事算数。**告示要长在物件上，不长在界面上。**

## 3. 录音：三档，从「补穿帮」到「能对质」

### 档一 · 只补穿帮（最小，最安全）

把 `story-clinic.js:1145` 那两句改成有条件的：

- 簿子里有 `rec-axuan` → 原文照演，一个字不改。
- 没有 → 他不戴耳机。改成：

> 罗启明：「录音带咗嚟？」
> 章慧琪：「……十四号那晚我冇按。门底有嘢，我净系用耳听。」
> 他没有追问。笔尖在纸上停了一下。
> 罗启明：「咁今晚开始录。唔好净系靠耳——耳会记住你想听嘅。」
> （note：`noRecYet`「他问录音，我交唔出。他叫我由今晚开始录。」）

顺带把「呢卷我日日听」和「有一晚唔好开录音」也挂到同一个条件上。

**代价**：第 8 关一段条件台词 + 一条 note。不动必做，不动关卡结构，不动对照纸。
**换到**：穿帮没了。但录音仍然不必要——只是不再露馅。

### 档二 · 把线接上（推荐）

档一 ＋ 三处：

**(a) 第 4 关「开录音」改真必做**
`levels.js:120` 加 `need: true` 与 `hint: "手机在茶几上，录一晚会怎样"`。
同时修 `waitDawn()` 那个反掉的判断：**没开录音、而门底真的响过**，也要提示一句再放行——现在的逻辑只抓「开了却漏看」，漏掉了「压根没开」。

**(b) 储物室门底的热点副标题从两档变三档**
现在是 `n.recording ? "那卷录音还在" : "锁着。"`——没录的时候写「锁着」，她（和玩家）以为门本来就锁着，根本不知道自己错过了什么。改成：

| 情形 | 副标题 |
| --- | --- |
| 声音还没到点 | 锁着。 |
| 有声音，在录 | 那卷录音还在。 |
| **有声音，没在录** | **门底有声。手机喺茶几上，冇开。** |

这一行就是全部的信号。不弹窗、不响提示音，只是让她站在门边时看见「哦，要录」。这是这个游戏唯一合法的暗示方式——**告示长在物件上**。

**(c) 第 8 关改成「他要录音」**
把 `HAND_RULE[8]` 那条「只交一样」的规矩留着不动（纸还是那张纸），在交完纸之后单开一步：

```
罗启明：「录音带咗嚟？」
  ├─ 有 → 「你把手机放到桌上。他戴上耳机。」→ 播一次（复用现成的 openAxuan）
  │        → 「把声好稳。似留过言，唔似当场叫你。」
  │        → flag("playedRec")，并 note 一句
  └─ 无 → 档一那段
```

为什么要单开一步而不是塞进交证物：交证物是「这一周最要紧的一样」，规矩立在那里，动了会把四关的节奏一起改坏。**他要录音，是另一件事：纸是她的记录，录音是她的耳朵。**

**这一刀落在最疼的地方**——因为他接下来那句「有一晚唔好开录音」，只有**听过**的人才有资格说。没听过的人说这句，是在指挥一个他没见过的东西。

于是第 9 关（8/23 夜～8/27「无声」）的 goal 分成两版：

| 分支 | goal |
| --- | --- |
| 听过 | 他听过那卷。他叫我关一晚，看车还动不动。 |
| 没听过 | 他叫我由今晚起日日录。我先要有一晚不开，才知道哪一样在动。 |

`paper-norec` 的正文也跟着分：没听过的分支开头多一句「他叫我日日录。我冇照做」——这句只在这个分支出现。

**为什么这三处就够了**：第 8 关的「他要录音」发生在第 9 关开对照纸**之前**。所以就算保险丝事后补发 `rec-axuan`，也补不回第 8 关那个当场空着的问句。**顺序本身就是一道闸**——不用动那个防卡死的保险丝，风险为零。

### 档三 · 让它能当武器（改动最大）

第 14 关走廊尽头（`levels.js:294`，`story-late.js:181`）是她第一次有资格反问的地方。加一支：簿子里有 `rec-axuan` 时，才出现「我录咗落嚟」这个选项，能播一次；对面的反应与没有时不同。

这一档才真正做到判据第 2 条（缺席换一条路）。但它要读 `story-late.js` 走廊整段重排，是四个档里唯一动主线的。

## 4. 拍立得：只做一处

三处可选，我建议只做第 3 处。

**(1) 拿掉万能口子**：`COMPARE_ROWS` 的 `sill` 行右侧去掉 `tonight:sill`，`time` 行去掉 `tonight:print`。
→ 照片变成某几行**唯一**能开的钥匙。但对照纸只要四行（共六行），少一行不疼，**代价不疼就等于没有代价**。**不建议。**

**(2) 相纸张数做实**：八张改四张。
→ 逼玩家挑着拍。但这个游戏里她只有四五个拍摄点，改了只是让某一次拍不成，不产生「该拍什么」的判断。**不建议。**

**(3) 初诊时有人当着她的面说出「相上面有时间」**（推荐）
第 6 关初诊看完纸之后，加两三句：

> 罗启明：「有冇相？」
> （有 `photo-sill`）「你把相纸举到灯下。」他说：「白边上写住几点。你口讲，冇时间；相有时间。」
> （没有）「下次带相。相上面有时间，你口讲，冇时间。」

这一句同时做完三件事：
- **解释了第 5 关她为什么拍那两张**（那时她只是「拍下来」，现在她知道那叫取证）
- **给第 16 关的时间线立了规矩**（`paper-16` 引的就是白边上的 14:30）
- **把「提前知道」合法地说出口**——是医生要的，不是我提示的

代价：一场两句，一个条件分支。**这是全部提案里性价比最高的一处。**

## 6. 刻意不做什么

- **不加证据收集进度、不加「这个以后有用」的提示条。** 一响就把「她自己搞不清什么算数」这个基调打掉了。
- **不改 `ensureCompareMaterials()` 的兜底逻辑。** 它防的是旧档和跳关卡死，收窄它会制造更难查的问题。第 8 关在前、补发在后，顺序已经够了。
- **不留死路。** 没录音、没拍照，每一关都要能走完，只是走向不同的话。
- **不为了「用上」而写第二遍。** `paper-16` 已经写了「出门前两张相」，初诊那两句不能再把同样的意思说一遍——它说的是**相纸白边上有时间**，这件事没人讲过。
- **旁白不写「她没有接」「她停住」。** 缺席要写她做了什么：他没说话／她没往下说／他站着没动。

## 9. 死锁：第 4 关「打完电话才开录音」过不了（10-28，已修）

用户报的：**先打电话、后开录音，任务栏就一直说「录音还没开」，开了等天亮也过不了，怎么按都过不了。**

### 根因：`waitDawn()` 先结算、后判断，把「八十九分那一秒」按死了

`waitDawn()` 原来的顺序是反的：

```js
n.min = 101;                    // ① 先把钟拨到天亮
n.fired.voice = true;           // ② 先把「那一声已经发生」标掉
...
const recDone = !!(hasEvidence("rec-axuan") || noted("voice"));   // ③ 才来判录音
if (!recDone) { tip("录音还没开……"); return; }                    // ④ 判不过，但状态已经毁了
```

录音关着的时候，91 分那一格里 `if (n.recording) note("voice", …)` 走不进去，
于是 `fired.voice` 被置 true、note 却没写。玩家看见「录音还没开」，照提示去开录音、再按一次——
钟已经停在 101，**91 分那一秒永远不会再触发**，`recDone` 永远 false。无限循环。

三条死路同时开着：
1. `n.min = 101` 让 `setInterval(tickNight)` 在 101 就停（`min >= 101` 直接 return），事件不再走。
2. `n.fired.voice = true` 让 `fireNightEvents()` 里 `if (n.fired.voice) return` 短路。
3. 「录音开着」这个状态只影响写不写字，**不影响能不能过**，所以开了也没用。

### 改法：先判、后算；判不过不动状态，钟接回去

```js
const recDone = !!(hasEvidence("rec-axuan") || noted("voice"));
if (!recDone) {
  tip(!n.recording ? "录音还没开。茶几上那部手机。"
     : (n.min || 63) >= 91 ? "录音开着。回屋里，点一下储物室门底。"
     : "录音开着。先别走，等那一声。", { nearBar: true });
  …
  if ((n.min || 63) < 101) startNightClock();   // 夜还没过完，把钟接回去
  return;
}
```

四条原则，以后写这一类结算都照这个来：

- **拦下来的那条路，一个状态都不许改。** 改了就等于「玩家这一次没做成，但那件事已经被记成做过了」。
- **拦下来之后，路要还留着。** 原来 `stopNightClock()` 之后不重启，提示说「先别走，等那一声」，
  可钟停了就永远等不到那一声，玩家只能读档。现在按 `min < 101` 把钟接回去。
- **提示要分三态**，不是一句「录音还没开」：没开／开了但还没到 91 分／开了、过了 91 分但还没听。
  三种情况该做的事不一样（开录音／等／去点门底）。
- **判据要用「玩家手上真有的东西」**：`hasEvidence("rec-axuan") || noted("voice")`，
  不是 `n.recording`（录了但没听，不算这一夜做完了）。

### 顺带：自己录的东西，听过就归档，不再问「记不记下来」

`openAxuan()` 原来走 `showVoicemail(..., keep = axuanItem())`，而 `showModal` 里

```js
if (k === "memo" || keep) …   // 先命中
```

`keep` 一给就落到 `showClueModal`，**必须点正文下划线才算归档**。
玩家点开、听完、按「好」——没归档，任务栏的「开录音」还挂着，等天亮又被叫回来点门底。

这一卷是她**自己录的**，不是捡来的纸：听过就等于在手机里。
现在 `openAxuan()` 一进来就 `note("voice", …)` ＋ `fileEvidence(axuanItem())`，不再问。

### 副标题从「说状态」改成「说动作」

`storageSub()`：

| 情形 | 原来 | 现在 |
| --- | --- | --- |
| 那一声还没发生 | 「锁着。」 | 「锁着。」 |
| 录音开着 | 「门缝里有人在说话。」 | 「手机录着。门缝里有人在说话。」 |
| 录音关着 | 「门底有声音。」 | 「门底有声音。手机在茶几上，没开。」 |

「门缝里有人在说话」是一句**状态**，玩家读成「这里有事，等会儿再说」；
加上「手机录着」才是**动作**——现在就该点。
