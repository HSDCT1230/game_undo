# 通关核对清单（十六关）

> 本文件由 `tools/通关清单.mjs` 从 `游戏/assets/levels.js` 直接生成，改关卡后重跑即可。
> 用途：自动检查只能证明「不白屏、不缺图、不报错」，证明不了「该出现的按钮出现了」。
> 那份只能靠人点一遍——照着这张清单走，每一步点不出来就是真问题。

## 怎么用

1. `cd 游戏 && python -m http.server 8080`，浏览器开 `http://127.0.0.1:8080/?dev`。
2. `?dev` 会显示跳关面板；怀疑某一关有问题时，直接跳过去单测那关（`?level=N`）。
3. 每一关**只看带 ★ 的项**——那是过关必须满足的条件（`need: true`），缺一项就卡住。
4. 圆括号里的「触发」是这一项对应的画面／事件名，找不到就说明触发没出来。
5. 卡住时先按 F12 看控制台；再对照本关 ★ 项，确认是「条件没满足」还是「按钮根本没画出来」。

## 走完之后

若某关卡住，按这三条分辨：

1. **条件没满足**：★ 项还是灰的 → 看它的提示，通常是漏点了屋里的某样东西（`屋里看清四样`、`看三样`计数类）。
2. **触发没出**：该出现的画面根本没出现 → 查 `story-*.js` 里这段的入口函数是否被 `S.xxx` 前置条件挡住。
3. **点了没反应**：按钮在但点下去无事发生 → 控制台多半有报错，把报错连同关卡号记下来。
