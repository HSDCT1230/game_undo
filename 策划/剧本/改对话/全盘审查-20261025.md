## 0. 这一版动了什么

### 0.1 已修：第 2 关死锁（`levels.js`）

`advance` 加了 `ready: readyShown`，另在 `levelReady()` 旁边新增一个辅助函数：

```js
// 「看得见的必做都做完了」——给那种「必做要靠按往下才发生」的关用。
// levelReady() 不认 show()，会去等一条还没放行的任务，然后永远等下去；
// 但整体放宽也不对（比如第 6 关要等表姐的电话挂断才算数）。所以只在这里放开。
function readyShown() {
  const L = levelNow();
  if (!L) return true;
  return L.tasks.every((t) => !t.need || t.done() || (t.show && !t.show()));
}
```

实测（无头 Chrome，从 hub 走真实按钮，不用 `?level=` 跳关）：

| 步 | 结果 |
| --- | --- |
| 四样看清 + 问过周生，uraGate 未置位 | `levelReady=false`（第 5 条还没现身）→ **按钮出现**「交定金，拿钥匙」 |
| 按下按钮 | 进对话，末尾浮出「掏出笔电，上廿八屋查清楚」 |
| 看完新闻、还没记进簿 | `levelReady=false`，仍然过不了 |
| 记进簿 | `levelReady=true` → 拿钥匙、进第 3 关 |
| 全检 | 0 ERROR（Flag 设 48 读 48，图片 189 张） |

没有动 `levelReady()` 本身。第 6 关那类「要等表姐挂电话」的严格门槛仍然有效。
