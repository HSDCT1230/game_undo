## B. 主动加审（包括但不限于）

### B1. 因果与信息权限

- [ ] 玩家／角色是否知道了不该知道的（真名林伟森、小鱼全名、谁逼跳、陈「我爱他」等一章禁区）
- [ ] 噪音与锁结局分开：旁支只改温度／笔记，不偷偷改主时间线日期
- [ ] 「不是同一只鬼」上门硬门槛仍在；天台伸手硬门槛仍在

### B2. 角色口吻（全量，禁抽查）

- [ ] 章：碎、收回、要证据；勿演讲／太懂自己
- [ ] 罗：短句、术语带白话、守界；勿讲课腔、替她做完情绪结论
- [ ] 陈：碎、半句、方便话；勿长独白、林的词、把醋说破
- [ ] 美娟：汤／沙发／锁门；勿第一句精神科宣判、点破家豪暗恋
- [ ] 周：和善短句、会改口；勿一上来阴恻恻、台词太聪明自揭在演
- [ ] 粤语 `text`／普通话 `zh`：角色话才有 `zh`；旁白／选项／帖／短讯惯例无 `zh`

### B3. 诊所弧阶段感

- [ ] 1→4 依赖与试探不倒挂；「问他精神」前三次咽住、第四次才出口
- [ ] 喜欢说漏在第三次；四诊可回调「你当冇听见」

### B4. 证物／日记／网页一致性

- [ ] 日记 `body`、笔记文案、对白提及同一物件时细节不打架（颜色、有无字、在谁口袋）
- [ ] 图槽与文案一致（天井不是树；走廊尽头是储物室门；全家福背面铅笔等——见待补图／设定）
- [ ] 黑料附件：旧闻涂名露「鱼」＋偷拍；一章不写睡过、不写逼跳过程

### B5. 分支与汇合

- [ ] 每个选项有后果类型（主路／旁支／汇合／锁）；旁支汇回主路
- [ ] Flag 表有置位、有读取；无「写了从没人读」或「读了从没人写」（全检标记对也要语义对）
- [ ] 二～四章若只动文档：标明「样板未做」，勿假装已进 `story-*`

### B6. 技术卫生（改台词常踩）

- [ ] `游戏/index.html` 保持 ASCII；壳字改 `core.js`
- [ ] 相关脚本 `?v=`／`PIC_VER` 已 bump
- [ ] 不把密钥、一次性预览图、工程根临时图提交进该交的范围
