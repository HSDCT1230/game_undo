# 改对话 · 工作入口

慢慢改台词只看这一页。不限工具：记事本、VS Code、Cursor、DeepSeek、别的 AI 都行。  
**游戏里玩家听见的真相源是** `游戏/assets/story.js` 的 `text`（粤语）和 `zh`（普通话）。剧本 Markdown 是对稿参考；两边不一致时，以你刚改完、并已测过的那份为准，再把另一份跟上。

## 必守（改之前）

1. **地名**：Tai Kok Tsui 一律 **大角咀**，禁止「大角嘴」。  
2. **粤普两行**：角色当面／电话话才有 `zh`；旁白（`who` 为空）、选项 `label`／`prompt`、短讯／语音留言、廿八屋帖文首版不填 `zh`。  
3. **不是普通话模式**：界面始终粤语在上，`zh` 在下一行括号。  
4. **`index.html` 不要写中文**（编码会烂）；界面壳字在 `游戏/assets/core.js` 的 `fillShellChrome`。改完 `story.js` 只把 `index.html` 里 `story.js?v=` 加一。  
5. **诊所只有四次**：关 6／8／10／12。关 14「罗医生的秘密」不是第五次会诊。  
6. **假地名别钉真门牌**：荣汇街、十二乡、澄心、维港大学可假；区／商场／车站用真名。  
7. **不要先改** `levels.js` 的 `title`、未同步的 `diary.js` 证物正文、番外（不做进游戏）。

## 怎么改（推荐顺序）

1. **定关**：下表「关 → 入口函数」。一次只改一关或一类口吻。  
2. **对口吻**：[口吻与全检](改对话-口吻与全检.md) + [人物志](../人物/05-人物志.md) 该人「对白口吻」。  
3. **改字**：走 A／B／C 任一路径。`zh` 可增删润色，贴剧情与前后句，不要逐字硬译粤语。  
4. **全量自检**：该关（或你动过的函数）**每一条**角色话过一遍口吻与标点——不要抽查。清单见 [口吻与全检](改对话-口吻与全检.md)。  
5. **进游戏测**：打开 `游戏/index.html?level=N`（或 `?test`），走该关主路听一遍。  
6. **刷缓存**：`游戏/index.html` 里 `assets/story.js?v=` 改一个新后缀。

若改了必做／过关物 → 再对 [01 关卡](01-第一章-关卡.md) 与 `levels.js` 的 `tasks`／`goal`。  
若改了选项汇合／Flag → 再对 [08 对话分支](08-对话分支.md)。

## `story.js` 里一行长什么样

```js
line("罗启明", "我喺诊所。", { zh: "我在诊所。" })
//     说话人     text＝粤语主句         zh＝普通话（可润色，不必字字对）
```

- 引擎：`游戏/assets/talk.js` 的 `talkBody`——有 `zh` 才显示下行。  
- 可增删句：在**同一函数**数组里加／删 `line(...)`，别拆坏后面的 `{ goto: ... }`／`choices`／`flag`。  
- 带分支的长句可能写成 `line("章慧琪", flag("x") ? "…" : "…", flag("x") ? { zh: "…" } : { zh: "…" })`——两条分支都要改到。

## 导出／写回（路 C）

在项目根目录（有 `游戏/` 的那一层）执行：

```bash
node 策划/剧本/导出对白.mjs
```

生成（可删、可再导，默认不进 git）：

- `策划/剧本/_导出/对白-按函数.md` — 按函数分块，便于整段丢给 DeepSeek  
- `策划/剧本/_导出/对白-表格.md` — `| 函数 | 谁 | 粤语 | 普通话 |` 便于表格编辑  

写回时：

1. 在 `story.js` 用函数名跳转（如搜 `function clinic2`）。  
2. 按「谁 + 旧粤语／旧普通话」定位原 `line`，改 `text`／`zh`。  
3. 新增轮次：仿照邻行写完整 `line("谁", "粤", { zh: "普" }),`（注意逗号）。  
4. 跑全检 → `?level=N` →  bump `?v=`。

Windows 若 `node` 不在 PATH：用 Node 安装目录下的 `node.exe` 带上脚本路径即可。
