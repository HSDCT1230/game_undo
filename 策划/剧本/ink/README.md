# Ink 写稿（第一章）· Inky 用法

**只作写稿。** 游戏运行时**不读** `.ink`，玩家看到的仍是 `游戏/assets/story-*.js`。  
你在 Inky 里改完 → 跟我说「同步某某段进游戏」，我帮你抄进 JS 并跑全检。

---

## 一、打开

1. 打开 Inky（`E:\Inky\Inky.exe`）。
2. **File → Open** →  
   `G:\code\active\lab\vibe_undo\策划\剧本\ink\ch1.ink`  
   **必须开总入口**，不要只开分卷。
3. 左边应有：`_vars` / `early` / `clinic` / `late`。
4. 右边是**按关**的总菜单。点完一段后要重来：预览区 **↺ Replay**，或再点「« 回总菜单」。

---

## 二、为什么右边按关、左边仍三个文件

| | 放什么 |
| --- | --- |
| **右边菜单** | 第 2～16 关，一关一项（和游戏关卡表对齐） |
| **左边分卷** | `early`／`clinic`／`late` 三个文件（别拆成十六个） |

按关跳转方便找对白；文件仍按剧情阶段合卷，Inky 编译和 INCLUDE 更稳。  
**第 1 关（廿八屋）** 是网页操作，没有 Ink 对白。

---

## 三、改任意一段对白

1. 右边点进对应关（例如「第 12 关　今夜的约定」）。
2. 再点子菜单里的那一段；或左边打开分卷后 **Ctrl+F** 搜台词／`=== 函数名 ===`。
3. 在中间改字：
   - 粤语：直接写在行上  
   - 普通话：行尾 `# zh:……`  
   - 笔记：`# note:id=正文`（不要用 `|`）  
   - Flag：`~ xxx = true`
4. **Ctrl+S**，右边预览。
5. 要给玩家玩：跟我说同步哪一关／哪一段。

**关卡 ↔ 分卷速查**

| 关 | 标题 | 分卷 |
| --- | --- | --- |
| 2～5 | 看房～关怀 | `early.ink` |
| 6～12 | 初诊～第四次 | `clinic.ink` |
| 13～16 | 上门～天台 | `late.ink` |

**不在 Ink 里的：**

- 廿八屋网页、墙簿、日记簿界面 → `web-ui.js`／`web-data.js`／`diary.js`
- 枢纽热点旁白、邮件手机 UI → 多半在 `story-*.js` 的 hub／mail  

这类也跟我说，我改 JS。
