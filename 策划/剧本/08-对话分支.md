# 暗度 · 对话分支

对稿真相源：**选项类型、Flag、汇合、锁结局**。台词与当场选项文案仍以各章剧本为准；时间见 [时间线与因果](../设定/07-时间线与因果.md)。

## 读法

| 标记 | 意思 |
| --- | --- |
| **主路** | 推荐／默认推进 |
| **旁支** | 改变笔记、温度或时机，不改结局骨架 |
| **汇合** | 无论选哪条，下一场相同 |
| **锁结局** | 影响真结局／封条（不说那个名字）／温度，不能当纯旁白 |
| **样板** | `游戏/assets/story-*.js` 已实现（目前到 1-12 天台） |
| **未做** | 只在剧本里 |

规则：一～三章选项**没有对错**，只有权限和温度。**全书真结局／封条仍锁在四章真名**；第一章试玩另有三条天台收束（`endHurt`：罗掉棚轻伤／陈掉棚轻伤／女主险坠被救），由**前期发现**在天台结算时锁死，不是天台临时三选一。一章窗口：电话（含陈那句地址）、倾偈、站内留言、讨论区、墙簿、日记簿。汇出档三章才开。日记簿不在墙簿。写稿用 Ink：[`ink/`](ink/README.md)（不接运行时；`node tools/ink-check.mjs` 编译＋三结局断言，已挂进全检）。
