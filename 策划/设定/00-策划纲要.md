## 一句话

章慧琪住进待拆唐楼，被转介给精神科医生罗启明。鬼叠三层：周先生在演——他先是真想收租，住了半个月后被匿名信和调查剪报逼成下策；阿明看见的女鬼是小鱼，是他自己封了十年的罪；林伟森把这两层排成一场戏，要证明阿明的善良会再杀死一个女人。

## 时代与地域（2014 香港）

- 租盘：廿八屋口吻。讨论区可有她自己的求助帖。藤先生广告在墙簿侧栏，只作签名。
- 聊天：倾偈，只和表姐。报警：999。电话含陈那句诊所地址，不另开一层。
- 墙簿：熟人页。日记簿不放上面。收件箱不是倾偈。
- 2004 年通讯：即时通，显示名称「藤先生」。2014 年打开旧笔电里的汇出档，不连已关服务器。一章不打开这个档。
- 论坛：2004 校园网，2014 香港讨论区，ID 都是「藤先生」。
- 电话：月费 vs 储值卡。打印：旺印文仪店，不写便利店。
- 学校：虚构综合大学「维港大学」。罗启明、林伟森读内外全科医学，五年，2000 年入，2005 年夏毕业。陈家豪读社会学，三年，2001 年入，2004 年毕业。同一书院、相邻宿舍，因夜间自修室与洗衣房认识。不同房、不同专业，也不同届。
- 工作：阿明白天公立医院精神科，晚上湾仔澄心私家。白袍只在医院。陈家豪 2004 年投考见习督察，2014 年任深水埗警区刑事调查队督察；便装出勤，休班不配枪。警察身份不赋予万能权限——私人查资料会留下审计记录，可触发纪律／刑事调查。
- 唐楼：深水埗荣汇街 28 号，楼高六层、无电梯。周住 4 楼前座，后座租给慧琪。后楼梯上天台，天台有水箱和晾衫架。八月湿热。陈从街底跑上天台，所以是六层。
- 租约：现金、口头、无印花。正因如此才平。周七月底自己放盘，是真的想租，不是为了赶人。



## 两处房产（周的钱）

1. **西贡十二乡村屋**（2012 年 9 月）：违规削坡、堵塞后山排水，暴雨后山泥倾泻。丽芬、阿轩死。人寿保险受益人周，已到账。2012 年 8 月 8 日加保，加保部分可争议期至 2014 年 8 月 8 日——正片时已过。公司内部对这宗索赔仍有一截复核没关（削坡纪录对不上）。土木署当天灾加疏忽。罪证（涂改维修令、现场相、加保批单）只放他自己前座。
2. **深水埗荣汇街 28 号唐楼**（2014）：市区重建研究／收购名单挂了一年多。楼高六层、无电梯。周住 4 楼前座，七月底自己把后座挂上廿八屋，真想收租。玩具和全家福先是从村屋搬来的遗物，08-15 起才被拿来演鬼。

周一开始想租。林不代放盘。08-14 信到，下午试收回失败，当晚才演鬼。勒索为什么成立、筛人、接触（信开场、电话催加快）、三次误读见 [因果与名词](06-因果与名词.md)。她进诊室后的浅笑和帖里的依恋，是林催周加快的原因，不是开场理由。

## 类型与规则

- 玩法：对话 + 可点界面（网页、聊天、记事册、录音、保单）。不是动作游戏。
- 分关。每关一个地方、一句「要做」、一张清单、一个看得见的过关动作。门诊自己成一关。一章十六关，见 [01 关卡](../剧本/01-第一章-关卡.md)。后半段（星期六弧）节奏见同文件「后半段节奏」：周间加异样，诊室收人；前半听人，后半听屋；上门破例，不破身份。
- 笔记只记录玩家点过的矛盾。未对上的暗线显示为「噪音」，不自动破案。
- 禁止上帝视角独白。禁止一声名字播完十年。
- 每个 POV 看到同一事件的不同权限。
- 粤语口语写在引号里，叙述用书面。
- **去 AI 味**：少用「不是……是……」「唔系……系……」整齐对立句（人物口癖或剧情锁句除外，如林要阿明认的那句）；少写「停了一下」「笔停住」「没有催」「目光移开」等空舞台指示——改写具体动作或感官；忌治疗腔口号短句（「你讲。我听。」「我听到。」）。对白与叙述贴合生活中文，可略带书面文艺。
- 心理上的事要专业，但玩家用生活说法就能听懂。病历上可以留医生的字；笔记、对白、旁白立刻用白话再说一遍。对照见下表。
- **对白口吻（三人）**
  - **罗启明**：直白、短句、好懂。一章四次门诊可以用术语，但同一句里就要拆开讲：主诉、日间功能、社会支持、现实检验、过度警觉、安全行为、减少暴露、鉴别、知情同意。不用「白话：」当标签，不用比喻（时间系纸、刀柄递笔、耳会补一句）。「治疗关系倾斜」「会谈焦点」只留病程，嘴里不读。可以漏脆弱和忧郁：声低、手抖、停半拍、我帮唔到、我脏。听人时温柔，说到自己就收。
  - **陈家豪**：直白、碎、日常。差人口语可以有。不准林的词（容器、人人有份、再揽一次锅）。帮忙说成方便。爱不出口。
  - **林伟森**：阴鸷。礼貌笑着问过头的问题。试探、越界、不把心思说全。容器可以从他嘴里出来，像针。要阿明认的那一句，直说「唔系鬼。系要你再讲一次：系我害嘅」，不要说「课」，也不要说「再揽一次锅」。怒留在出门后的备忘，诊室里仍笑。

## 心理词：专业意思，生活说法

医生会用左边的字。玩家要对上的是右边。对白里林可以说「容器」，但同一场必须有人用白话拆开。

| 本作用的词 | 生活里怎么理解 | 正片怎么露 |
| --- | --- | --- |
| 对不上那个女人 | 事实记得（车、水喉、三秒）。影像跟场景走：白房安全，画面出不来；回到那条像当年的走廊，画面又插进来。他知道自己在哪、对着谁，话却先对空气讲。数呼吸是把自己数回来。整晚失忆、鬼上身、落药——这几条都不成立。陈删笔记只让他查不到自己写过没有。 | 1-9、1-11 他亲口。闪回只给碎片（灯、尽头、唔好走），不给小鱼的名字和死法 |
| 封／封条 | 他自己定的规矩：不提那个全名、十一月不当纪念日、当普通医生，免得再有人出事。看人不超过三秒是同一套规矩，但一章不演——「三秒」在一章只指水龙头延迟。 | 一章可露一个「鱼」，不给张晓鱼。四章才看见不看人、以及他怎么骗自己 |
| 容器 | 林的说法：把人当盒子，把心事、罪过倒进去。 | 阿文谈这个词；阿明或笔记要补一句「装心事的盒子」 |
| 不要写「当药」 | 拿人当止痛药来睡，是旧稿里的谎。正片给章的信不写这句，也不写他跟谁睡过。 | 一章信是坠楼旧闻加阶梯偷拍；男人那张相留在抽屉，四章才见 |
| 建议中止 | 停掉这一段治疗，转介别的医生。病程可写「治疗关系倾斜」：病人不讲失眠，把医生留成私人倾诉；再约下去，病治不成，医生也不再是医生。 | 四章六月：对白只说白话（倒转、帮唔到、转介）。术语留病程。三章病程原句旁边立刻白话 |
| 治疗关系倾斜 | 看病倒转了。本应你讲病、我帮你睇；变成你占用我、问我。 | 只写病程。对白由阿明用白话拆开，不把术语读出来 |
| 对谁都停 | 他对每个人都会停下来，把话听完，然后走开。谁都觉得被认真听过，谁都不是唯一。对白不要只丢「停」，带出「听完就走」。不要用「光」这个词。 | 四章林恨的就是这一条 |
| 缝 | 事情对不上的地方：车自己转、脚印是湿的、周的话和现场不合。慧琪会追这些。对白写「对不上」，不要只丢「缝」。 | 一章她录音、对照；林选她因为她不会用「旧楼」抹掉 |
| 再讲一次：系我害嘅 | 林要的就是再做一次：再有一个女人出事，阿明再信「系我害的」。不要说「课」，也不要说「再揽一次锅」。对白直说：唔系鬼。系要你再讲一次：系我害嘅。 | 四章他亲口；即时通最后一条 |
| 下一台 | 阿明自己的词：把女朋友当成排队的下一个病人 | 四章即时通原句保留，笔记写成「下一个病人」 |
| 读唔完／护士证拿唔到 | 小鱼读三年护理，差半年毕业；口头「暂缓独立值班」未入永久档案，她听成考唔到注册护士证、做唔成屯门医院护士。不要用「牌」——玩家会误会是扑克、麻将或别的隐喻 | 4-2 评语场；对白写「读唔完」「护士证」「屯门医院」 |
| 树可以换 | 林的备忘：这个女人不成，换下一个也行 | 只出现在他私人字；对白不要当诗 |

比喻第一次出现，用生活说法拆开。不要只丢「刀」「盒子」让玩家自己猜。不要用「光」。

## 三层鬼

周负责演鬼，阿明负责看见鬼，林负责把他们安排在同一场戏里。分层见 [人物关系图](../人物/人物关系图.md)；哪一章可以钉死见 [时间线](07-时间线与因果.md)。

## 四章停在哪里

真相源是各章剧本文首的「停／不准」。此处只做索引：

1. 章慧琪伸手。陈翻出女儿墙，外墙棚架档住，重伤未死。不给周全案，不给阿明病因。
2. 陈重伤生还（坠楼被棚架挡住，不是天台撞腰了事）。爱没被接住。救人不抵消越权与控制。
3. 周这一层可以先扣着，十二乡他仍不认。女鬼仍在。阿明只得到：有人骗过我。
4. 玩家说出林伟森。阿明改口，不播蒙太奇。章慧琪还站着。诊室里按不住他。公司开除，差人通缉恐吓和盗用档案。跳楼和十二乡定不了他。

## 剧本体例

```
## 场次编号 地点 · 时间
目的：这一场玩家要得到什么、不许得到什么
界面：可点什么
【对话】
【选项】后果写在选项后
【笔记】仅当玩家点过
【暗线】可见 / 实际
```

选项没有对错，只有权限和温度。天台、改口、是否打开旧号，才锁结局。分支总表见 [对话分支](../剧本/08-对话分支.md)。
